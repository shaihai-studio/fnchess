函数棋 游戏的规则与操作教程
================================================================================

函数棋是一款"数学函数 + 策略对战"的双人（或人机）回合制网页游戏。一方挑选"目标
格"，另一方编写数学函数表达式让函数图像穿过目标格得分，同时避开对手设置的"禁止区"。
表达式越简洁，得分越高。

================================================================================
一、核心概念
================================================================================

棋盘
  - 坐标系：左下角为原点，横轴为 x（实数），纵轴为 y（实数）。
  - 本地/联机对战的棋盘范围随回合自动扩展（第 1~4 回合 ±5，之后 +1/每回合，上
    限 ±10）；闯关模式固定 20x20；竞速模式固定 20x20（坐标 -10~9）。

函数表达式
  - 以变量 x 为核心的数学表达式，如 x+1、x^2、sin(x) 等。
  - 系统将该表达式在棋盘范围内逐个像素采样，绘制成连续折线（即函数图像）。
  - 若折线穿过"目标格"即命中；若穿过"禁止区"即犯规。

元素锁定（Element Lock）
  - 对手可以在回合开始前锁定某些数学元素（如 +、-、sin、数字等），本轮你不能在
    表达式中使用被锁定的元素。

回合流程（本地/联机模式）
  1. SELECT_TARGET — 当前回合的"选格者"挑选目标格（棋盘上的网格）。
  2. SET_FORBIDDEN — 选格者的对手设置禁止区（不得穿过的格子）。
  3. SET_LOCKS    — 对手锁定特定元素，限制选格者可用的运算符/常量。
  4. INPUT_FUNCTION — 选格者输入函数表达式，系统求值、渲染并判定命中。
  5. EVALUATE     — 判定结果（命中/犯规），结算得分。
  6. SWITCH_PLAYER — 交换角色，进入下一回合。

前 4 回合特殊规则（热身期）
  - 第 1~4 回合不设禁止区（0 个）且不可锁定元素（0 个锁），让新手熟悉机制。
  - 选格顺序：A 选第 1~2 回合，B 选第 3~4 回合（交替执行）。
  - 从第 5 回合起：
    - 禁止区数量由难度决定（见下文）。
    - 元素锁定数量：第 5~12 回合最多 1 个锁，第 13 回合起最多 2 个锁。
    - 禁止区设置者：奇数回合为 B，偶数回合为 A。

================================================================================
二、函数表达式语法
================================================================================

支持的运算符（按优先级排列）：
  +　加法　　　　　　　　　　　　　 -　减法（也可作一元负号）
  *　乘法　（不可省略，不能用 ）     /　除法
  ^　乘方　（如 x^2、x^(1/2)）     !　阶乘（如 x!、3!）
  ( )　括号用于分组和控制优先级

支持的一元函数（可嵌套）：
  sin(x)　正弦　　 cos(x)　余弦　　 tan(x)　正切
  log(x)　常用对数　 ln(x)　 自然对数
  sqrt(x) 平方根（等价于 x^(1/2)）
  abs(x)　绝对值
  exp(x)　e 的 x 次方

支持的数学常量：
  π 或 pi　　圆周率　≈ 3.14159
  e　 　　　自然常数 ≈ 2.71828
  i　　　　 虚数单位（√−1）

中间计算支持复数，但最终函数图像仅在虚部足够小（< 1e-10）时认为可绘制。竖直渐
近线（如 1/x 的 x=0 处）会自动断开，不会错误命中。

示例合法表达式：
  x^2 + 3
  sin(x) + cos(2*x)
  sqrt(x^3 - 4*x)
  e^x
  (x+1)! / (x-1)!
  abs(tan(x/π))

================================================================================
三、命中判定
================================================================================

目标格命中
  - 系统将函数图像采样为密集折线（每段 20 个采样点），逐段检查是否与目标格区域
    相交。
  - 判定为"视觉穿过"：只要折线进入格子内部即算命中（宽口径），不需要所有点都
    在格内。
  - 适应容差：约 0.8 像素（范围=5），范围更大时容差按比例缩小。

禁止区判定
  - 与目标格判定机制相同。函数图像进入任意一个禁止区即犯规，本回合直接失败。

================================================================================
四、得分体系
================================================================================

回合基础得分
  - 命中所有目标格且未触碰禁止区 → 成功。
  - 表达式越简洁（字符数少、结构简单）得分越高。

函数类型评分（简洁度）
  - 常量函数（如 3）       → 最高分
  - 一次函数（如 x+2）     → 高分
  - 二次函数（如 x^2+1）   → 中高分
  - 三角函数（如 sin(x)）  → 中等分
  - 复杂/高次函数          → 基础分
  - 函数越复杂、嵌套越深，评分越低。

得分的最终用途
  - 本地/人机对战：每回合得分计入双方累计；先获得超过总回合数一半胜场者获胜。
  - 闯关模式：通过即可获得 1~3 星评定（取决于表达式质量）。
  - 竞速模式：计时通关，根据用时获得 1~5 星评定。

================================================================================
五、游戏模式
================================================================================

① 本地对战（2P）
  - 两名玩家轮流进行回合。A 先手。
  - 难度选择决定：禁止区数量、目标格数量、回合时间限制。
  - 难度配置：
    ┌──────────┬──────┬──────┬──────┬──────┬───────┐
    │ 难度     │目标格│禁止区│时间限│回合数│胜利需 │
    │          │  /回合│ /回合│ (秒) │      │ 胜场  │
    ├──────────┼──────┼──────┼──────┼──────┼───────┤
    │ 简单     │  3   │  1   │ 600  │  4   │  3    │
    │ 普通     │  2   │  4   │ 300  │  6   │  4    │
    │ 困难     │  1   │  16  │  60  │  8   │  5    │
    │ 专家     │  1   │  64  │  60  │  12  │  7    │
    └──────────┴──────┴──────┴──────┴──────┴───────┘

② 人机对战（AI）
  - 规则与本地对战相同，对手由 Summa 机器人接管。
  - 玩家始终为 A 方。

③ 闯关模式（Campaign）
  - 单人模式。关卡从 levels.txt 加载（共 81 关，含"专家 ???"难度）。
  - 每关预设目标格、禁止区和锁定元素，无需手动选格/禁格阶段。
  - 棋盘固定 20x20（可无限扩展）。
  - 通关进度自动保存到 localStorage。
  - 关卡星级评定：表达式命中和简洁度综合评定。
  - 自定义关卡包（自制关卡）：
    - 难度界面提供"导入 .js 关卡"与"粘贴文本"两个入口。
    - 支持导入 .js/.json 文件，或直接粘贴 JSON 数组 / {levels:[...]} / JS 数组字面量文本。
    - 导入后难度网格中出现以文件名命名的"自制关卡"入口，点击进入全部关卡（无解锁限制）。
    - 自定义包与官方关卡完全隔离：不写内置通关进度、不计入 LR∑、不记录最佳记录。

④ 竞速模式（Race）
  - 单人模式。30 个等级，每级 10 题，每题目标格/禁止区/锁定元素随机生成。
  - 固定 20x20 棋盘（坐标 -10~9）。
  - 从等级 1 开始自动晋级，按总用时评定星级：
    ＜100s    ★★★★★
    ＜150s    ★★★★
    ＜300s    ★★★
    ＜1000s   ★★
    否则      ★
  - 每题失败可重试，不扣时间；失败重试次数不限。
  - 竞速最高成绩自动保存到 localStorage。
  - 自定义竞速关卡（自制关卡）：
    - 竞速界面提供"自定义竞速"按钮，弹窗中可设置允许区数量（1~398）、禁止区数量
      （0~398，与允许区之和须小于 400）、锁定元素数量（启用反三角函数前 0~20，启用后
      0~23）。
    - 开始后随机生成一盘自定义竞速对局；允许区即目标格，禁止区即禁止格，锁定元素随机
      落在允许区内。
    - 自定义局与官方竞速完全隔离：不晋级、不解除解锁、不计星级、不记录最佳成绩、不显示
      NEW RECORD；完成后只能重玩同一自定义局（重新随机布局）。

⑤ 测试模式（Test）
  - 自由测试模式，无目标格、禁止区、元素锁定、时间限制。
  - 棋盘 20x20（坐标 -10~9）。
  - 适合调试表达式或尝试新函数。

⑥ 联机对战（P2P + 匹配大厅）
  - 通过 PeerJS 实现浏览器直连对战；需先启动信令服务器（`server/` 目录）。
  - 匹配大厅（Lobby）：通过 WebSocket 连接服务器的 /lobby 端点（与 PeerJS 同端口），
    支持"创建房间（进大厅）""加入"与"大厅列表"三种入口。
  - 创建房间：房主填写配置后登记到大厅，得到房间码；访客可在列表或输入房间码加入。
    A 为房主，先手。
  - 长效模式（可选）：勾选后房间有效期 30 分钟（房间号以 00 开头），普通房间约 5 分钟。
  - 房间到期会被服务器清理，房主侧收到"房间已过期"提示。
  - 房主离开联机界面时，已创建的房间保留（顶部状态条常驻），有对手加入仍会自动切入对
    局；只有关闭页面才弹出确认提醒（房间将失效）。
  - 观战：房主默认允许观战（建房时可取消勾选）。
    - 开局后若观战开启，房间仍保留在大厅列表并标记"对战中"，其他玩家可直接点"观战"进入。
    - 观众为只读模式（禁点击/悬停/提交/清除），可实时看到房主状态快照；观战不走 WebRTC，
      数据经大厅 WebSocket 转发。
    - 房主对局中可随时切换观战开关；关闭会立即踢出观众并从大厅隐藏房间。
  - 掉线处理：断线弹窗仅提供"返回主菜单"，不做重试。

⑦ 关卡编辑器（Editor）
  - 单人创作工具，用于制作自定义闯关关卡包。
  - 在主界面选择"关卡编辑器"模式并点击"开始游戏"，即就地打开编辑器（不再跳转独立页面）。
  - 可编辑：关卡 ID、难度、nextId、目标格（targetCells）、禁止区（forbiddenCells）、
    锁定元素（lockedElements）；支持多关卡增删。
  - 操作：左键放置目标 / 右键放置禁止（网格右上角按钮可互换左右键）；长按拖动可框选或
    路径涂满；支持 Ctrl+Z 撤回；点击精度可选 1/2 ~ 1/10，点击基准可选左下角/中心。
  - 导出：生成 .js 关卡包片段，可复制或下载（如 campaignLevels.fragment.js），
    供闯关模式"导入"使用。

================================================================================
六、规则细节
================================================================================

选格规则
  - 目标格、禁止区格子不可与之前回合已使用的格子（usedCells）重叠。
  - 选目标格时可点击已选中的格子取消选择。
  - 达到最大目标数后，每选一个新格子会自动替换最后一个。

元素锁定规则
  - 锁定元素限制书写者可用的运算符/函数/常量。
  - 竞速模式自己设计的"冲突组"保护机制：+/-/^ 组不能全部同时锁定，
    !/sin/cos/tan 组同理（防止完全无解）。
  - 锁定元素不可为当前回合已见于目标表达式中的元素。

限时规则
  - 输入表达式阶段有倒计时。超时则该回合失败（视为未命中/超时），直接切换玩家。
  - 其他阶段（选格、禁格、锁元素）无时间限制。

路径连续性
  - 系统采样函数并生成折线，相邻采样点的跳跃（如 1/x 在 0 两侧）会被自动检测
    并断开，避免错误命中。

usedCells 机制
  - 已被选为目标格或禁止区的坐标在本局中记录为 usedCells，后续回合不可再用。
  - 竞速每道题重新随机生成，不记录 usedCells。

================================================================================
七、技术说明（供开发者参考）
================================================================================

- 解析引擎：FunctionParser.js（AST 解析，支持复数中间运算）。
- 碰撞检测：CollisionDetector.js（视觉采样法，每段折线 20 个采样点）。
- 坐标系统：GridSystem.js 提供统一的"数学坐标 ↔ Canvas 像素"换算。
- 联机信令：PeerJS + server/index.js（Express + PeerServer）。
- 存储：localStorage 用于闯关进度、竞速最佳成绩保存。
- 项目技术栈：纯 HTML5 Canvas + 原生 ES6 JS，无框架/无打包器/无 npm 依赖。

================================================================================
八、操作教程
================================================================================

快速启动
  - 直接打开 index.html 即可游玩（纯前端网页，无需安装任何依赖）。
  - 联机对战需额外启动信令服务器：进入 server/ 目录，参考该目录说明安装依赖并启动
    （npm install && npm start 等）。

开始游戏（通用流程）
  1. 主菜单选择模式：本地对战 / 人机对战 / 闯关 / 竞速 / 测试 / 联机对战 / 关卡编辑器。
  2. 按需配置难度、回合数、时间限制等参数。
  3. 点击「开始游戏」进入对应模式。

本地 / 人机对局操作流程
  1. 选格：选格者点击棋盘网格挑选目标格（再次点击可取消；超过上限后，新选的格子自动
     替换最后一个）。
  2. 禁格：对手设置禁止区（函数图像不得穿过的格子）。
  3. 锁元素：对手锁定特定元素，本轮书写者不能使用。
  4. 输入表达式：书写者在输入框输入函数表达式（如 x^2+1），右侧有实时函数预览与
     KaTeX 数学预览，确认后提交。
  5. 判定：系统判定命中/犯规并结算得分，进入下一回合。

闯关模式操作流程
  1. 选择难度（或导入的自制关卡，见下文「导入关卡包」）。
  2. 在关卡列表选择关卡进入，按要求编写表达式命中目标格。
  3. 通过即获得 1~3 星，通关进度自动保存到 localStorage。

竞速模式操作流程
  - 从等级 1 开始逐级挑战，每题重试不扣时间；按总用时评定 1~5 星，最高成绩自动保存。
  - 自定义竞速：点击「自定义竞速」按钮，设置允许区 / 禁止区 / 锁定元素数量后随机生成
    对局（自定义局不晋级、不计星级、不记录最佳成绩）。

联机对战操作流程
  1. 先启动 server/ 目录下的信令服务器。
  2. 主菜单选「联机对战」：
     - 创建房间（进大厅）：房主填写配置登记到大厅，获得房间码；
     - 加入：输入房间码或在大厅列表中点击加入。
  3. 房主为 A 方先手；可勾选长效模式（房间有效期 30 分钟）与观战开关。
  4. 对局流程与本地对战相同；断线时弹窗仅提供「返回主菜单」。

关卡编辑器操作流程
  1. 主菜单选择「关卡编辑器」模式，点击「开始游戏」即就地打开编辑器。
  2. 左侧表单编辑当前关卡信息：关卡 ID、难度、nextId。
  3. 在棋盘上绘制格子：
     - 左键点击：放置目标格（targetCells）。
     - 右键点击：放置禁止区（forbiddenCells）。
     - 网格右上角按钮可互换左右键用途。
     - 长按拖动：可框选一片或路径涂满。
     - 支持 Ctrl+Z 撤回误操作。
     - 点击精度可选 1/2 ~ 1/10；点击基准可选左下角 / 中心。
  4. 多关卡管理：可新增、删除关卡，并切换编辑。
  5. 导出关卡包（任选其一）：
     - 「复制导出文本」（或 Ctrl+S）：把全部关卡文本复制到剪贴板。
     - 「下载」：直接下载 .js 关卡包文件（默认名 campaignLevels.fragment.js，
       可在文件名输入框改名，无扩展名会自动补 .js）。
     - 「复制当前关卡」：仅复制当前这一关的文本。

导入关卡包操作流程（闯关模式）
  1. 主菜单选择「闯关」模式，进入难度选择界面。
  2. 使用难度网格右下角两个入口之一：
     - 「导入 .js 关卡」：点击后选择 .js 或 .json 关卡包文件。
     - 「粘贴文本」：弹出窗口中直接粘贴关卡包文本（可自定义关卡包名称）。
  3. 导入成功后提示"已导入 ×××：N 关"，难度网格出现以文件名命名的「自制关卡」按钮。
  4. 点击该按钮进入全部关卡，可直接游玩，无解锁限制。

关卡包格式说明
  - 关卡字段：
      id             关卡 ID（必填）
      difficulty     难度
      nextId         下一关 ID
      targetCells    目标格坐标数组（必填），如 [{"x":-0.5,"y":0}]
      forbiddenCells 禁止区坐标数组（缺省自动补空）
      lockedElements 锁定元素数组（缺省自动补空），如 ["+"]
  - 支持的文本格式（解析器自动兼容）：
      1) 标准 JSON 数组：     [{...},{...}]
      2) 含 levels 的对象：   {"levels":[...]}
      3) JS 数组/对象字面量： 如 const X=[...]、export default [...] 等赋值式文本
      4) 编辑器「复制导出文本」的关卡对象列表正文（无外层中括号）
  - 校验要求：每关必须有 id 与 targetCells 数组，否则导入会报错
    （"关卡数据缺少 id 或 targetCells"）。
  - 建议：直接用关卡编辑器导出后原样导入，不要手工删字段。
