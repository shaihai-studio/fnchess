函数棋 游戏规则
================================================================================

函数棋是一款"数学函数 + 策略对战"的双人（或人机）回合制网页游戏。一方挑选"目标
格"，另一方编写数学函数表达式让函数图像穿过目标格得分，同时避开对手设置的"禁止区"。
表达式越简洁，得分越高。

================================================================================
一、核心概念
================================================================================

棋盘
  - 坐标系：左下角为原点，横轴为 x（实数），纵轴为 y（实数）。
  - 本地/联机对战的棋盘范围随回合自动扩展（第 1~4 回合 ±5，之后 +1/每回合，上
    限 ±10）；闯关模式固定 20x20；竞速模式固定 20x20（坐标 -10~9）。

函数表达式
  - 以变量 x 为核心的数学表达式，如 x+1、x^2、sin(x) 等。
  - 系统将该表达式在棋盘范围内逐个像素采样，绘制成连续折线（即函数图像）。
  - 若折线穿过"目标格"即命中；若穿过"禁止区"即犯规。

元素锁定（Element Lock）
  - 对手可以在回合开始前锁定某些数学元素（如 +、-、sin、数字等），本轮你不能在
    表达式中使用被锁定的元素。

回合流程（本地/联机模式）
  1. SELECT_TARGET — 当前回合的"选格者"挑选目标格（棋盘上的网格）。
  2. SET_FORBIDDEN — 选格者的对手设置禁止区（不得穿过的格子）。
  3. SET_LOCKS    — 对手锁定特定元素，限制选格者可用的运算符/常量。
  4. INPUT_FUNCTION — 选格者输入函数表达式，系统求值、渲染并判定命中。
  5. EVALUATE     — 判定结果（命中/犯规），结算得分。
  6. SWITCH_PLAYER — 交换角色，进入下一回合。

前 4 回合特殊规则（热身期）
  - 第 1~4 回合不设禁止区（0 个）且不可锁定元素（0 个锁），让新手熟悉机制。
  - 选格顺序：A 选第 1~2 回合，B 选第 3~4 回合（交替执行）。
  - 从第 5 回合起：
    - 禁止区数量由难度决定（见下文）。
    - 元素锁定数量：第 5~12 回合最多 1 个锁，第 13 回合起最多 2 个锁。
    - 禁止区设置者：奇数回合为 B，偶数回合为 A。

================================================================================
二、函数表达式语法
================================================================================

支持的运算符（按优先级排列）：
  +　加法　　　　　　　　　　　　　 -　减法（也可作一元负号）
  *　乘法　（不可省略，不能用 ）     /　除法
  ^　乘方　（如 x^2、x^(1/2)）     !　阶乘（如 x!、3!）
  ( )　括号用于分组和控制优先级

支持的一元函数（可嵌套）：
  sin(x)　正弦　　 cos(x)　余弦　　 tan(x)　正切
  log(x)　常用对数　 ln(x)　 自然对数
  sqrt(x) 平方根（等价于 x^(1/2)）
  abs(x)　绝对值
  exp(x)　e 的 x 次方

支持的数学常量：
  π 或 pi　　圆周率　≈ 3.14159
  e　 　　　自然常数 ≈ 2.71828
  i　　　　 虚数单位（√−1）

中间计算支持复数，但最终函数图像仅在虚部足够小（< 1e-10）时认为可绘制。竖直渐
近线（如 1/x 的 x=0 处）会自动断开，不会错误命中。

示例合法表达式：
  x^2 + 3
  sin(x) + cos(2*x)
  sqrt(x^3 - 4*x)
  e^x
  (x+1)! / (x-1)!
  abs(tan(x/π))

================================================================================
三、命中判定
================================================================================

目标格命中
  - 系统将函数图像采样为密集折线（每段 20 个采样点），逐段检查是否与目标格区域
    相交。
  - 判定为"视觉穿过"：只要折线进入格子内部即算命中（宽口径），不需要所有点都
    在格内。
  - 适应容差：约 0.8 像素（范围=5），范围更大时容差按比例缩小。

禁止区判定
  - 与目标格判定机制相同。函数图像进入任意一个禁止区即犯规，本回合直接失败。

================================================================================
四、得分体系
================================================================================

回合基础得分
  - 命中所有目标格且未触碰禁止区 → 成功。
  - 表达式越简洁（字符数少、结构简单）得分越高。

函数类型评分（简洁度）
  - 常量函数（如 3）       → 最高分
  - 一次函数（如 x+2）     → 高分
  - 二次函数（如 x^2+1）   → 中高分
  - 三角函数（如 sin(x)）  → 中等分
  - 复杂/高次函数          → 基础分
  - 函数越复杂、嵌套越深，评分越低。

得分的最终用途
  - 本地/人机对战：每回合得分计入双方累计；先获得超过总回合数一半胜场者获胜。
  - 闯关模式：通过即可获得 1~3 星评定（取决于表达式质量）。
  - 竞速模式：计时通关，根据用时获得 1~5 星评定。

================================================================================
五、游戏模式
================================================================================

① 本地对战（2P）
  - 两名玩家轮流进行回合。A 先手。
  - 难度选择决定：禁止区数量、目标格数量、回合时间限制。
  - 难度配置：
    ┌──────────┬──────┬──────┬──────┬──────┬───────┐
    │ 难度     │目标格│禁止区│时间限│回合数│胜利需 │
    │          │  /回合│ /回合│ (秒) │      │ 胜场  │
    ├──────────┼──────┼──────┼──────┼──────┼───────┤
    │ 简单     │  3   │  1   │ 600  │  4   │  3    │
    │ 普通     │  2   │  4   │ 300  │  6   │  4    │
    │ 困难     │  1   │  16  │  60  │  8   │  5    │
    │ 专家     │  1   │  64  │  60  │  12  │  7    │
    └──────────┴──────┴──────┴──────┴──────┴───────┘

② 人机对战（AI）
  - 规则与本地对战相同，对手由 Summa 机器人接管。
  - 玩家始终为 A 方。

③ 闯关模式（Campaign）
  - 单人模式。关卡从 levels.txt 加载（共 81 关，含"专家 ???"难度）。
  - 每关预设目标格、禁止区和锁定元素，无需手动选格/禁格阶段。
  - 棋盘固定 20x20（可无限扩展）。
  - 通关进度自动保存到 localStorage。
  - 关卡星级评定：表达式命中和简洁度综合评定。

④ 竞速模式（Race）
  - 单人模式。30 个等级，每级 10 题，每题目标格/禁止区/锁定元素随机生成。
  - 固定 20x20 棋盘（坐标 -10~9）。
  - 从等级 1 开始自动晋级，按总用时评定星级：
    ＜100s    ★★★★★
    ＜150s    ★★★★
    ＜300s    ★★★
    ＜1000s   ★★
    否则      ★
  - 每题失败可重试，不扣时间；失败重试次数不限。
  - 竞速最高成绩自动保存到 localStorage。

⑤ 测试模式（Test）
  - 自由测试模式，无目标格、禁止区、元素锁定、时间限制。
  - 棋盘 20x20（坐标 -10~9）。
  - 适合调试表达式或尝试新函数。

⑥ 联机对战（P2P）
  - 通过 PeerJS 实现浏览器直连对战。
  - 需先启动信令服务器（`server/` 目录）。
  - 一人创建房间，另一人加入。A 为房主先手。

================================================================================
六、规则细节
================================================================================

选格规则
  - 目标格、禁止区格子不可与之前回合已使用的格子（usedCells）重叠。
  - 选目标格时可点击已选中的格子取消选择。
  - 达到最大目标数后，每选一个新格子会自动替换最后一个。

元素锁定规则
  - 锁定元素限制书写者可用的运算符/函数/常量。
  - 竞速模式自己设计的"冲突组"保护机制：+/-/^ 组不能全部同时锁定，
    !/sin/cos/tan 组同理（防止完全无解）。
  - 锁定元素不可为当前回合已见于目标表达式中的元素。

限时规则
  - 输入表达式阶段有倒计时。超时则该回合失败（视为未命中/超时），直接切换玩家。
  - 其他阶段（选格、禁格、锁元素）无时间限制。

路径连续性
  - 系统采样函数并生成折线，相邻采样点的跳跃（如 1/x 在 0 两侧）会被自动检测
    并断开，避免错误命中。

usedCells 机制
  - 已被选为目标格或禁止区的坐标在本局中记录为 usedCells，后续回合不可再用。
  - 竞速每道题重新随机生成，不记录 usedCells。

================================================================================
七、技术说明（供开发者参考）
================================================================================

- 解析引擎：FunctionParser.js（AST 解析，支持复数中间运算）。
- 碰撞检测：CollisionDetector.js（视觉采样法，每段折线 20 个采样点）。
- 坐标系统：GridSystem.js 提供统一的"数学坐标 ↔ Canvas 像素"换算。
- 联机信令：PeerJS + server/index.js（Express + PeerServer）。
- 存储：localStorage 用于闯关进度、竞速最佳成绩保存。
- 项目技术栈：纯 HTML5 Canvas + 原生 ES6 JS，无框架/无打包器/无 npm 依赖。
