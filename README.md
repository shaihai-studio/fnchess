## fnchess 函数棋
【函数棋 fnchess】用函数打仗的数学策略游戏。
构造表达式让曲线穿过目标格，避开禁止区。表达式越短得分越高，只用一个x就能拿5分满分。

根目录运行下面代码：
```powershell
npm install # 安装依赖

npm start # 运行
npm run build # 桌面端安装包编译
```

- 81关闯关，4级难度递进
- 本地对战/人机对战/自由测试
