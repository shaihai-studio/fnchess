# 函数棋 v2.0.0 版本对比说明（写给 1.0.0 玩家）

> 对比基线：`baa0f034`（2026-06-25 正式版 1.0.0）→ 当前 `main`（2026-08-16，v2.0.0）
> 共约 120 个提交。
>
> **阅读指引**：本文档按「页面 / 模式」介绍 **1.0.0 → 2.0.0 新增的功能**（第一 ~ 十二章），玩家开新版本后优先看这些；所有**优化、修复、内部重构**统一集中在文末第十三章，不影响玩法的改动都在那里，不必逐一了解。

## 一、开始界面 / 主界面（start-modal）

### 1.1 模式按钮直接启动（2.0.0 核心改动）
- **删除**主界面底部"开始游戏"大按钮，改为点击右侧模式按钮直接进入对应模式/对局。
- 模式按钮拆为**父级 + 子级**两级：
  - 父级按钮（对战 / 闯关 / 竞速）点击后展开子菜单；
  - 子模式按钮点击后**直接进入**对应流程，不再需要先选中再点"开始游戏"。
- 各模式入口行为：
  - **本地对战 / 人机对战**：弹配置确认弹窗（回合数 + 难度 + 时间限制 + 模式名 + 开始/取消），确认后开局；
  - **测试模式**：直接开局，无弹窗；
  - **经典闯关 / 标准竞速**：打开选关界面；
  - **关卡编辑器**：直接打开编辑器；
  - **竞速试炼场**：弹自定义设置弹窗；
  - **联机对战 / 联机竞速**：打开房间弹窗；
  - **AI 训练检查弹窗**：保留原有逻辑。

### 1.2 关卡编辑器独立入口
- **关卡编辑器**：从对战子菜单移为**独立主模式按钮**，点击即激活（不再需要先选中模式）。
- 选择关卡编辑器时，左侧回合数 / 难度选择器自动禁用。

### 1.3 新增模式一览
- 现在主界面共 4 个父级模式：**对战（本地/人机/联机）、闯关（经典/编辑器）、竞速（标准/试炼场/联机）、测试**。

## 二、对战模式（本地 / 人机）

### 2.1 反三角函数 + 数学预览
- 支持**反三角函数**：`asin / acos / atan` 等可在函数中直接使用。
- 表达式输入区新增 **KaTeX 数学预览**（`#math-preview`）：输入时实时显示规范的 LaTeX 排版，一眼看清函数写对了没。
- 反三角函数有**闯关解锁机制**：需在闯关中解锁后，才能在对战里使用（见第四章）。

### 2.2 函数白名单调整
- `exp` / `log` 移出可用函数列表（不再支持），保留 `ln`；数学常量 `e` 仍可用。
- 影响范围：表达式解析、Latex 显示、AI 生成的函数、角色描述、签名校验等全链路同步。

### 2.3 AI 子系统与角色
- AI 控制器拆分为**独立子系统**，对战模式新增专属样式。
- AI 新增两个完整角色生成体系：
  - **多函数 AI**（AIFunctionBuilderMulti）：一次构造含多函数组合的 AI 表达式；
  - **表达式处理**（AIExpressionHandler）+ **AI 配置持久化**（AIPersistence）：AI 行为可保存复用。

## 三、联机对战（P2P）——从"半成品"到"完整实现"

1.0.0 时代联机只有基础框架，2.0.0 期间**完整实现并持续打磨**，这是本版本最大的新增内容。

### 3.1 全量状态同步 + 回合互斥（核心）
- **全量状态实时同步**：棋盘、函数、回合状态完整同步；
- **回合操作互斥**：双方不会同时操作导致冲突，动作确认期间也允许发送状态同步，每次变更立即生效。

### 3.2 自托管信令服务器 + 纯数字房间码
- 新增**自托管联机信令服务器**（`server/index.js`，Express + PeerJS Server + WebSocket），支持局域网 / 公网联机，无需依赖公共 PeerJS 服务器；
- 房间码简化为**纯数字**，方便口述 / 输入。

### 3.3 匹配大厅（lobby）
- 新增 **WebSocket 匹配大厅**（`/lobby`）：
  - 房主建房后自动**登记房间**（带难度/回合/时间限制/观战开关配置）；
  - 访客**拉取房间列表**并**申请加入**，房主收到加入通知；
  - 房间开局 / 取消登记 / 房主断线时自动从列表清理；
- 大厅按**排位 / 休闲模式隔离房间**；
- **排位房间 ELO 距离过滤与排序**：只显示 ELO 分相近的对手，输入框实时钳制。

### 3.4 排位 / 休闲模式 + ELO 体系
- 建房时可选 **排位 / 休闲**：
  - **休闲**：不计 ELO、无重连、无中途判负；
  - **排位**：完整 ELO 体系（初始 1200、K=32、胜/负/平记录），房主上报、按房间码去重，双端结算天然对称；
- **中途退出 / 断线弃权判负扣分**：房主主动解散也判负，访客收到房主解散判自己胜（完全对称，双端一致）；
- 无昵称时首局先引导**设置昵称**再联机。

### 3.5 断线重连与对局恢复
- **断线重连**：断线后 60 秒宽限期（20 次×3s），带倒计时提示；
- **对局恢复**：访客大退（刷新 / 关页）后可**恢复对局**；
- 断线判罚对称：按"本方信令丢失"判定——`self_reconnect_failed` 本方负 / `opponent_lost` 对方负；未开局退出给中性文案。

### 3.6 对战体验
- 新增联机对战**开场 VS 动画**；
- 退出流程简化：仅剩确认退出，无二次确认；
- 新增对方主动退出通知、观战昵称展示、退出确认弹窗。

## 四、闯关模式（Campaign）

- **分数关卡**：新增特殊计分关卡类型（算出的数值参与计分）。
- **反三角函数解锁机制**：特定关卡解锁 `asin / acos / atan` 等在函数栏中的使用（解锁后对战模式可用）。
- 关卡总数固定 **109 关**。
- **自定义关卡包**中的分数关不再强制锁定小数点（可自由输入）。

---

## 五、关卡编辑器（独立主模式）

- 从对战子菜单移为**独立主模式按钮**，独立入口直接打开。
- **编辑能力扩充**：
  - 支持**分数关**；
  - 支持编辑**目标点 / 禁区 / 锁定元素**；
  - 内置**示例关卡**。
- 编辑器工具栏与悬浮输入栏交互体验重构，编辑操作更顺手。

---

## 六、竞速模式（单人竞速 Race）

- **竞速模式重做**：走格子答题的完整单人竞速玩法，配置难度 / 耐力开局。
- **关卡数量确定**：竞速 = **30 关**。
- **竞速试炼场（自定义）**：自定义难度、回合、时间限制进入试炼。
- **服务端权威计时**：竞速排行榜改为服务器计时（`raceSessionId` + 开始时间戳），成绩公平可信，不再由前端自报时间。
- **段位体系（9 级）**：流星体 → 小行星 → 矮行星 → 行星 → 恒星 → 矮星系 → 星系 → 星系团 → 宇宙。
  - 阈值：0 / 100 / 200 / 300 / 400 / 600 / 800 / 1000 / 1600；
  - 保护分 300（低段位扣分保护）；弃权固定扣 30 分；
  - 段位图标更新；支持**段位查询与多玩家进度显示**（房内所有人段位一目了然）。
- **分数倍率**：难度 7 档（0.6 ~ 1.5 倍）、耐力 4 档（0.6 ~ 1.5 倍），倍数越高分越高。

## 七、联机竞速对战（Race Battle，多人大乱斗）

### 7.1 模式本身（2026-08-10 新增）
- **多人联机竞速对战模式**：多人同关竞速（房主建房、访客加入），比谁先完成关卡。
- 房间支持多名玩家（`maxPlayers`），访客存于 `guests` 列表。
- 每名玩家**独立进度**，房主权威收集进度快照，失败方 / 完成方**实时排行**。

### 7.2 房主迁移（Host Migration）
- 房主断线时**自动迁移**：新房主继承对局；迁移失败自动建随机 `rg_` 访客 peer 重连。
- 迁移按 **slot×1.5s** 错开，新房主收集完整快照广播后全房继续。

### 7.3 模式隔离与心跳
- **模式隔离**：竞速房与 1v1 房严格区分（Peer id 前缀 `race_`），互不串房。
- **心跳检测**：3000/9000ms 心跳，检测掉线并触发恢复 / 迁移。

### 7.4 房间交互
- 新增**被踢提示**；匹配大厅退出处理完善。
- 新增**面板折叠**功能、选格超时逻辑。

## 八、排行榜（Leaderboard）

### 8.1 榜单体系（2026-08-04 起搭建）
- **在线排行榜**：支持多榜单切换（tab）：
  - `lr`：积分总分榜（保留前 1000）；
  - `tt`：旧星分总榜（历史榜保留）；
  - `rtN`：**竞速分关 Time Attack 榜**（每关独立小榜，比单关最快用时，升序取最短，前 100）；
  - `pl1 / pl2`：分数关专属榜；
  - `elo`：联机排位 ELO 榜（含胜负平，前 1000）。
- 提交积分后**自动刷新已打开的排行榜**。
- 界面新增：`#leaderboard-myrank` 我的排名、关卡下拉选择器（`#race-level-select`，rt{cur} 标签映射）、**举报按钮**。

### 8.2 防作弊体系（方案 A）
- **签名与核验**：前端用密钥对成绩签名，服务器验签（失败回传细分 code）；
- **IP 风控**：限速闸门（2s）、IP 新身份拦截、`too_fast / ip_banned` 错误提示；
- **房间级去重**：`eloSettled / raceSettled` Set 防 A/B 双端重复上报；
- **总分核验**：分数关明细与总分一致性校验；
- **举报机制**：榜单行内举报按钮；
- **重置进度联动**：支持重置进度时选择性清除排行榜成绩；
- 老玩家兼容：旧无签名数据兼容处理。

### 8.3 ELO 榜
- 标准对称 ELO 结算公式（`updateElo`），双端结果天然一致。

### 8.4 彗星榜（pl）
- 实现**彗星分关榜**，胜利弹窗带**彗星进度条**。

## 十一、观战功能（Spectate）

- **对局观战**：房主默认开启观战，开局后房间保留在大厅列表，观众凭房间码加入。
- 房主关闭观战 → 房间立即从大厅移除、观众被踢出。
- 房主 `spectate_sync` 推送状态快照 → 服务器广播给所有观众，实时同步战况。
- 观战昵称展示；竞速房强制禁止观战。

---

## 十二、服务器（server/index.js，面向搭建者）

### 12.1 功能清单
- PeerJS 信令服务（`/peerjs`），noServer 模式 + 统一 Upgrade 分发（`/lobby` 与 `/peerjs` 同端口共存）；
- 匹配大厅 WebSocket（`/lobby`）：房主登记 / 访客拉取 / 加入申请 / 房间清理；
- 观战广播（spectate_sync）；
- **在线排行榜**：lr / tt / rtN / pl1 / pl2 / elo 多榜，内存 Map + `leaderboard.json` 落盘；
- **ELO 计算**（K=32，初始 1200）+ 房间去重；
- **竞速权威计时**（raceSessionId + startTs）与竞速分数结算（难度/耐力倍率 + 保护分）；
- **服务器通知**（`/notice`，改 `notice.json` 无需重启）；
- **版本检查**（`/version`，前端对比 `GAME_VERSION` 提示新版本）；
- 限速 + IP 风控 + 验签细分错误码。

### 12.2 部署
- `cd server && npm install && npm start`（默认端口 9000）。
- 依赖：express、ws、peer、docx（rule-gen 用）。

### 12.3 工具脚本
- `server/rule-gen.cjs`：读取 `游戏规则.txt` 自动生成排版的 `游戏规则.docx`（封面/页眉页码/表格交替底色），规则文档一键生成。

## 十三、优化与体验改进（统一集中在此，不影响玩法的改动都在这里）

> 前面十二章讲的是"新功能"；这一章把所有修复、体验优化、内部重构集中列出。老玩家无需全部了解，扫一眼即可。

### 13.1 视觉与 UI
- **统一深色背景** + 画布布局响应式适配（2026-08-08 UI 大重构）；
- **统一游戏色调**：对战 = 金、闯关 = 蓝、竞速 = 青的主题色体系；
- 移除旧底部控制面板；
- 使用 CSS 变量重构布局；
- 主界面子模式按钮：进入后**不再默认高亮**，改为悬停时显示主题色高亮（对战金 / 闯关蓝 / 竞速青）。

### 13.2 移动端适配
- 移动端**内联元素面板**（元素输入改为内联面板）；
- 移动端视口适配、弹窗滚动、按钮尺寸、闯关难度按钮弹性布局等一系列适配修复。

### 13.3 输入与表达式优化
- **保留解析式**：输入不丢失（配合懒加载）；
- 统一 `prepareInputPhase()` 清理机制，消除两套表达式清理分叉；
- 修复 π 后接字母时生成未定义 LaTeX 命令的问题；
- 切换 / 重置时清理历史函数与格子，避免残留。

### 13.4 稳定性修复（问题清单 P2-P21）
- 修复函数棋问题清单（P2-P21）全部有效项；
- 实现 `GameController.finalizeRound / startNextRound`，消除 P2P 崩溃；
- 修复表达式求值与竞速重试状态残留；
- 修复音频音量、回合轮换与排行榜签名并发问题；
- 联机相关批量修复：状态同步引用共享、多目标禁止区检测、快照乱序覆盖、高频发送、远端快照回放循环、冗余重绘、操作同步滞后、回合推进死锁、状态覆盖回滚、联机状态同步卡死、连续超时判负反加分等。

### 13.5 内部重构与清理
- **UIController.js 模块化拆分**：拆为 10 个原型扩展模块（`files/js/ui/*.js`），便于维护；
- 删除重复 race-victory-modal、无用字体文件、死代码与调试方法；
- 前端**懒加载 PeerJS**，加入加载失败降级；
- **AGPL 许可头 + 资源许可说明**（KaTeX、PeerJS、信令服务器依赖）。
