# 函数棋 版本更新说明：从 1.0.0 到 2.0.0.2

> 这是一份写给玩家的更新说明。下面的内容只讲「你能在游戏里感受到的变化」，尽量不用专业术语。如果你想看技术层面的改动，请翻到文末「技术更新与优化」一节。

**版本对比**：`1.0.0`（正式版） → `2.0.0.2`（当前最新版）

从 1.0.0 到现在，游戏经历了 100 多次更新，几乎是「脱胎换骨」的一次大升级——原来只有最基础的闯关、人机对战和陪你练棋的伙伴「Summa」，现在新增了**竞速模式**、**在线联机对战**、**在线排行榜**、**关卡编辑器**，并对画面与手机体验做了全面重做。

---

## 一、全新玩法：竞速模式 ⏱️

**是什么**：在规定时间内，用尽可能短的函数表达式去"吃掉"目标格子，比的是手速和巧思。

- **30 个关卡**：从易到难循序渐进，新手也能轻松上手。
- **分关计时榜（Time Attack）**：每一关都独立记录你的最好成绩，谁用的时间最短谁就排前面，不再被总分一锅烩。
- **9 级天体段位**：从「流星体」一路升到「宇宙」，赢了就涨分、段位图标实时变化，肉眼可见自己的进步。
- **多人联机竞速（新）**：可以和多位玩家同场竞速，实时看到彼此的进度条和名次，谁先通关一目了然。
- **段位查询 & 进度显示（新）**：随时查看自己当前段位、距离下一档还差多少分。

**你能得到的好处**：多了一种"短平快"的玩法，通勤、等车随手来一局；段位系统让你有明确目标，越玩越有成就感。

## 二、全新玩法：在线联机对战（P2P 实时对战）🤝

**是什么**：和真实的对手在线实时下棋，双方每一步都即时同步，就像面对面下棋一样。

- **排位模式 / 休闲模式**：想认真上分选排位（计入段位分），想随便玩玩选休闲（不计分、更轻松）。
- **匹配大厅**：进大厅就能看到正在等待的房间，点一下就能加入，不用再手动交换房间号。
- **断线自动重连**：网络抖一下也不怕，掉线后会在 1 分钟内自动重连，对局不丢失。
- **房主迁移（新）**：房主万一掉线，系统会自动把"房主"交给还在场的玩家，对局照常进行，不会全员掉线。
- **观战功能**：可以旁观别人的对局，学习高手的思路。
- **再战 & Summa 表情包互发**：打完一局可以直接"再来一局"；对局中点击右下角的表情按钮，就能把Summa的 9 种情绪立绘（开心 / 思考 / 得意 / 惊讶 / 难过 / 生气等）发给对手，连观战的人也能发，对战更有气氛。
- **开场 VS 动画 & 对手昵称**：开局有专属入场动画，也能看到对手的昵称，更有对战感。
- **公平结算**：中途退出、掉线都有明确的胜负判定和扣分规则，避免有人"跑路"影响你上分。

**你能得到的好处**：终于能和朋友、和全国玩家真刀真枪地比了；重连和房主迁移让联机不再"一断就废"。

## 三、全新系统：在线排行榜 🏆

**是什么**：把你和所有玩家的成绩放到一起排名，成绩由服务器统一记录，公开透明。

- **三种榜单**：
  1. **总分榜**：比谁的综合实力强。
  2. **竞速分关榜（Time Attack）**：每一关单独排名，专看你的竞速速度。
  3. **胜负 / 彗星榜**：记录闯关的胜场与进度。
- **防作弊机制**：成绩上传带加密签名，服务器会校验，刷分、造假的成绩会被拦下，排行榜更干净。
- **提交后自动刷新**：你刚打完的成绩，打开排行榜立刻就能看到，不用手动刷新。
- **可选择性清除**：重置进度时，你可以只清本地成绩、保留排行榜成绩，反之亦然。

**你能得到的好处**：有了"全国排行榜"，你清楚自己排第几；防作弊让你努力换来的名次货真价实。

## 四、全新工具：关卡编辑器 ✏️

**是什么**：自己动手设计关卡，做一套属于你或你朋友的"函数棋题目"。

- **自定义关卡包**：自由设定棋盘、目标、规则，保存成你自己的关卡。
- **一键导入**：别人做好的关卡包，可以直接导入到游戏里玩。
- **从主界面直接进入**：编辑器是独立的主模式按钮，点一下就开始编辑，不用在层层菜单里找。

**你能得到的好处**：游戏内容由你扩展——可以出题考朋友，也可以挑战社区里的高手关卡。

## 五、界面与操作的大升级 🎨

- **开始界面重做**：原来要点"开始"再选模式，现在**模式按钮直接启动**（闯关 / 竞速 / 联机 / 排行榜 / 编辑器一目了然），少点好几下。
- **统一深色主题**：整体配色更协调、更护眼，长时间看不累。
- **手机 / 平板全面适配**：按钮、布局会自动适应屏幕大小，手机上也能舒服地玩；竖屏时输入键盘贴底、横屏时居中，表达式变长也不会挡住棋盘。
- **悬浮输入栏 & 内联元素面板**：输函数时，常用符号（常数、运算符等）就在手边，不用在远处找；显示区和预览区各自可滚动，长表达式也不乱。
- **实时公式预览（KaTeX）**：边输入边看到漂亮的数学公式render效果，写错一眼就能发现。
- **难度提示优化**：各个模式的难度说明更清楚，新手不会再"懵着进"。
- **面板可折叠**：联机对战时，信息面板能收起，把更多空间留给棋盘。

**你能得到的好处**：上手更快、看着更舒服、手机上也能随时玩。

## 六、数学与函数能力增强 📐

- **新增反三角函数**：`sin⁻¹`、`cos⁻¹`、`tan⁻¹` 等可用，能表达的函数更丰富；它们会在闯关里逐步解锁。
- **保留你写过的解析式**：切换模式或重开时，你上次写的函数会被记住，不用重新敲一遍。
- **小数锁定更合理**：自定义关卡里的"分数关"不再强制锁定小数点，编辑更自由。
- **函数白名单整理**：把设计范围外、容易误用的函数移除，只保留稳定好用的集合，避免写出"看起来对但实际算不出"的表达式。

**你能得到的好处**：能玩出更多花样，同时少踩"表达式无效"的坑。

## ⚠️ 可能影响你的操作变化（请注意）

1. **昵称最长 10 个字符**：现在起你的玩家昵称最多只能填 10 个字（含中英文），之前设过超长昵称的会在保存时被截断。
2. **房间码变成纯数字、6 位**：联机房间的"房间号"现在是一串 6 位纯数字，和朋友互报房间号时直接报数字即可，不再混字母。
3. **联机需要信令服务器**：在线对战依赖一个联网的"中转服务"。游戏已默认指向自托管地址；如果你自己部署，请在设置里填好信令服务器地址，否则搜不到房间、连不上对手。
4. **排行榜成绩归服务器管**：以前本地存的成绩，现在统一上传到服务器。换设备登录后，总分榜 / 竞速分关榜 / 胜负榜会以服务器记录为准。
5. **排位掉线会判负扣分**：排位模式里如果长时间连不上（超过重连宽限期），会按"弃权"结算并扣分；休闲模式不计分，相对宽松。
6. **开始按钮没了**：直接点主界面的模式按钮就能进对应玩法，不用再先点"开始"。
7. **关卡编辑器独立出来**：想做自定义关卡，直接点主界面的"编辑器"按钮，不再藏在"对战"子菜单里。

## 技术更新与优化（面向开发者 / 感兴趣的同学）

以下为 1.0.0 → 2.0.0.2 在代码与底层上的主要改动，按模块归类，力求详尽：

### A. 版本与构建
- 新增 `GameVersion.js`，集中管理 `GAME_VERSION='2.0.0.2'`，启动时与服务器 `/version` 比对，本地版本更旧则弹窗提示。
- 资源目录从仓库根统一迁移到 `files/`（js / css / fonts / images / bgm / sounds / geogebra-lite），路径规范化。

### B. 新增核心模块（1.0.0 时完全不存在）
- `RaceMode/RaceModeController.js`、`RaceMode/RaceModeManager.js`：竞速模式控制器，含 `TOTAL_LEVELS=30`。
- `RaceRoomController.js`：竞速联机房间与房主迁移。
- `P2PController.js`：P2P 实时对战同步（全量状态同步、回合操作互斥、断线重连、房主迁移）。
- `LeaderboardService.js`、`VerifyCrypto.js`：在线排行榜服务与成绩签名/核验防作弊。
- `MatchLobby.js`、`PlayerProfile.js`：匹配大厅与玩家档案（昵称、段位等）。
- `MathLatex.js`、`ComplexMath.js`：KaTeX 公式预览与复数/复杂数学支撑。
- `UIController.js` 拆分为瘦壳 + `files/js/ui/*` 共 41 个原型扩展模块（UICampaign / UIRace / UILeaderboard / UILobby / UIEditor / UIFloatKeypad / UIPhase / UISpectator / UIStart / racebattle/* / uip2p/* / uicore/*），加载顺序在实例化前完成 prototype 挂回。
- `UIEditor.js` 由单文件（983 行 `initEditor`）重构为编辑器物理拆分，含画布/笔刷/关卡管理/导入导出子模块；`GameController.js` 对战逻辑拆分出的 `SubController` / `GameStateManager` / `ControllerBridge` 等被纳入 `GameSubControllers/` 体系。
- `CampaignData.js` 取代静态 `campaignLevels.js`，支撑更灵活的关卡数据与分数关。
- `LICENSE` / `ASSETS-LICENSE.md`：补 AGPL 许可与第三方资源（KaTeX / PeerJS / 信令服务器）许可说明。
