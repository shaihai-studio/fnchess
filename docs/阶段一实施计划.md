# 阶段一实施计划：服务器中继权威计时（先堵竞速刷分）

> 依据：《大重构计划-服务端权威立项.md》阶段一
> 目标：rtN（竞速分关 Time Attack）用时由服务端权威计算，客户端本地用时仅兜底/展示，不参与排名。

## 协议设计

- 新增消息 `race_start`（客户端→服务端）：`{ type:'race_start', levelId, id }`
  - 服务端记录 `startTs = Date.now()`，生成随机 `raceSessionId`，绑定该 ws 连接，同一连接同时只保留 1 个活跃会话（每关一个）。
  - 回复 `race_start_result`：`{ type:'race_start_result', ok, raceSessionId, serverTs, code? }`
- 改造 `submit_score`（rtN 分支）：
  - 必须携带 `raceSessionId`（放 payload，参与签名防伪造）；无会话/会话不属于本连接/levelId 不匹配 → 拒绝。
  - 权威用时 `serverElapsed = (now - startTs)/1000`，低于 `raceFloorSeconds(levelId)` → `too_fast` 拒绝。
  - 会话一次性：上报后立即删除；TTL 10 分钟兜底清理。
