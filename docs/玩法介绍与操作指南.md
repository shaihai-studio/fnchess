## 一、三十秒认识这个游戏

**函数棋 = 数学函数 + 策略对战。**

两个人在同一个坐标系棋盘上轮流当「出题人」和「答题人」：

- **出题人**在棋盘上点一个格子当**目标格**，再点几个格子当**禁止区**，还可以**锁掉几个数学符号**（比如不许用 `+`）
- **答题人**写一个函数表达式（比如 `x+1`、`x^2`、`sin(x)`），让它的**函数图像穿过目标格**，同时**不能碰到禁止区**
- **表达式越短，得分越高** —— 写 `x+1` 比写 `1*x+1` 分高

一轮下来换人，最后比总分。就这么简单。

## 二、怎么打开它

### 最快：双击 `index.html`

打开文件夹，双击 `index.html`，浏览器就开了。**不用装任何东西。**

### 如果双击后有异常

有些浏览器在 `file://` 协议下会限制部分功能（比如自定义关卡包的导入导出）。
这时用本地服务器打开（电脑需装过 Python 或 Node.js，二选一）：

```bash
# 有 Python 的话（推荐，命令行里输入）
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000

# 有 Node.js 的话
npx http-server -p 8000
```

> 看不出有没有 Python？在命令行里敲 `python --version`，有版本号就行。

### 手机上玩

把整个文件夹传到手机，用浏览器打开 `index.html`；或者部署到静态网站托管（GitHub Pages 等）后用网址访问。
游戏横竖屏都适配，**横屏体验最好**。

## 三、第一局：手把手带你走完一个回合

> 建议第一次先花两分钟去 **测试模式** 练手 —— 那里没有倒计时、没有目标格，随便画函数熟悉操作（见第五节）。

### 第 0 步：进游戏

1. 打开后点屏幕任意处（或按回车）→ 出现标题页
2. 点 **「开始游戏」** → 进入主界面
3. 左栏三个选择器先用**默认值**就行：难度「简单」、回合「8」、时间「普通棋」
4. 右栏点 **「对战模式」** → 弹出子菜单 → 选 **「本地对战」**
5. 点 **「开始游戏」** → 开局！

### 第 1 步：你是出题人 —— 选目标格

- 屏幕底部提示「请点击棋盘选择目标网格」
- **在棋盘上点一个格子**，它会亮起金框并标上 `T1`
- 简单难度只需选 **1 个**（普通 2 个、专家 3 个）
- 点错了？再点一次那个格子可以取消
- 选完点右下角圆形的 **「✓ 确认」**（或按回车）

### 第 2 步：你是出题人 —— 设禁止区

- 底部提示让你设置禁止区
- **再点棋盘上的格子**，它们变成红色并标 `F1`
- 这是给对手增加难度用的 —— 对手的函数图像碰到这里就判失败
- 第 1~8 回合最多只能设 **1 个**
- 设好点 **「✓ 确认」**

### 第 3 步：锁定元素（第 5 回合才会出现）

- **第 1~4 回合没有这一步**，会自动跳过
- 第 5 回合起：底部键盘变成"锁定视图"，**点任意一个符号按钮就锁住它**
- 比如锁 `+`，对手这轮就不能用加号了
- 被锁的按钮会变红底；再点一次取消
- 确认后进入下一步

### 第 4 步：换你答题 —— 写函数

这一步换对方操作，现在轮到你了：

- 屏幕下方浮出**计算器式键盘**，棋盘上显示坐标系
- **点按钮拼出你的表达式**，比如依次点 `x`、`+`、`1`，输入框就显示 `x+1`
- **右侧会实时显示渲染好的数学公式** —— 先看一眼它长什么样，对不对
- 写错了：点 `⌫` 删一个，点 `AC` 全清空
- 需要 `sin`、`ln`、根号？点键盘下方的 **「fx」** 展开函数面板
- 写好点 **「提交」**（或按回车）

### 第 5 步：看结果

- 你的函数图像会**从左往右画出来**
- 穿过目标格 → 目标格闪绿光 → 弹出「✓ 成功 +5 分」
- 碰到禁止区 → 闪红光 → 「✗ 失败 -1 分」
- 没画到目标格 → 「✗ 失败 -1 分」
- 倒计时归零还没提交 → 「超时！-1 分」，直接换人

### 第 6 步：换人，重复

- 屏幕显示「轮到 玩家B」，然后重复第 1~5 步
- **注意规则固定**：第 1 回合 B 当出题人、第 2 回合 A 当、第 3 回合 B……永远如此
- 全部回合打完 → 弹出「游戏结束」，分高者胜

### 想复盘？点「查看游戏报告」

结算弹窗里点这个按钮，能看到**每个回合的完整明细**：谁出题、谁答题、写了什么表达式、结果如何、多少分。

## 四、得分规则：怎么拿高分

**只看一件事：你的表达式有多少个 token。**（token ≈ 一个符号块，`x`、`1`、`+`、`sin`、`(` 各算一个）

| token 数 | 得分 |
|---------|------|
| 1 ~ 2 个 | **5 分（满分）** |
| 3 ~ 5 个 | 4 分 |
| 6 ~ 9 个 | 3 分 |
| 10 ~ 15 个 | 2 分 |
| 16 个以上 | 1 分 |

**同样一条曲线，写法越短分越高：**

| 想画的东西 | 啰嗦写法 | 简洁写法 |
|-----------|---------|---------|
| 斜线 | `1*x+1` | `x+1` |
| 抛物线 | `x^2+0` | `x^2` |
| 过原点直线 | `x/1` | `x` |
| 水平线 | `x*0+3` | `3` |

**三条最实用的原则：**

1. **能省的 `*` 和 `()` 都省掉** —— 写 `2x` 不写 `(2)*(x)`
2. **先想"什么函数天然过这些点"，再想"怎么把它写短"**
3. **常见曲线背下来**：`x` 斜线、`x^2` 抛物线、`sin(x)` 波浪、`abs(x)` V 形、`sqrt(x)` 半支抛物线

**可用符号一览：**

- 运算：`+` `-` `*` `/` `^`（幂） `!`（阶乘） 括号
- 函数：`sin` `cos` `tan` `abs` `ln` `sqrt`
- 反三角：`asin` `acos` `atan`（**通关全部分数关后解锁**）
- 常量：`π` `e` `i`
- 变量：`x`

## 五、九个模式，分别怎么进、怎么玩

**统一入口：都在主界面右栏的四个模式按钮里。**

### ① 本地对战（2 人一台设备）

- **怎么进**：对战模式 → 本地对战 → 开始游戏
- **怎么玩**：两人轮流操作同一台设备，可先调难度/回合数/时间
- **适合**：和朋友面对面玩

### ② 人机对战（1 人 vs AI）

- **怎么进**：对战模式 → 人机对战 → 开始游戏
- **怎么玩**：对手是 AI「Summa」。**首次用某个难度对战时会先弹「唤醒 Summa」训练弹窗** ——
  它在你的浏览器本地学习，选一档训练规模（快速入门 100 万次 / 标准 500 万 / 深度 2000 万 / 极限 1 亿），
  训练完自动开局。**训练期间别切浏览器标签页**，后台会被限速。
- **注意**：训练耗时较长是正常的，越大的规模越强。

### ③ 闯关模式（1 人解题）

- **怎么进**：闯关模式 → 经典闯关 → 选难度 → 选关卡
- **怎么玩**：**90 个官方整数关 + 19 个分数关**，每关的目标格、禁止区、锁定元素都是预设好的。
  通关解锁下一关，按表达式简洁度给 **1~5 星**。**没有倒计时，可以慢慢想。**
- **难度分区**：1~29 简单 / 30~53 普通 / 54~69 困难 / 70~81 专家 / 82~90 无解
- **分数关**：通关全部简单难度后开放，共 19 关
- **重要**：**通关全部 19 个分数关，就解锁反三角函数** `asin` `acos` `atan`

### ④ 竞速模式（1 人比速度）

- **怎么进**：竞速模式 → 标准竞速 → 选等级
- **怎么玩**：**30 个等级，每级 10 道随机题**，从等级 1 逐级往上。
  开局有「3、2、1、GO!」起跑倒计时，然后开始计时。
  **每题失败可以无限重试，不额外扣时间**，放心试错。
- **评星**（按该级 10 题累计用时）：100 秒内 5 星 / 150 秒内 4 星 / 300 秒内 3 星 / 1000 秒内 2 星 / 更久 1 星
- **注意**：也需要通关当前等级全部 10 题才解锁下一级

### ⑤ 竞速试炼场（自定义练习）

- **怎么进**：竞速模式 → 竞速试炼场
- **怎么玩**：自己设「允许区 / 禁止区 / 锁定元素」的数量，随机生成一盘专属谜题
- **注意**：**不晋级、不计星、不记录成绩**，纯粹练手用

### ⑥ 联机竞速（2~4 人）

- **怎么进**：竞速模式 → 联机竞速 → 选排位/休闲
- **怎么玩**：多人同关竞速，实时看排名和进度条。需要**自己搭服务器**（见第九节）

### ⑦ 联机对战（2 人 P2P）

- **怎么进**：对战模式 → 联机对战 → 选**排位**（计 ELO 分）或**休闲**
- **怎么玩**：三种方式找人——
  - **建房间**：点「创建房间」，把生成的 **6 位纯数字房间码**报给朋友
  - **加房间**：输入朋友的 6 位房间码，点「加入房间」
  - **匹配大厅**：直接看正在等人加入的房间列表（排位房会按 ELO 相近排序），点「加入」
- **特色**：有 **VS 开场动画**、**观战**、**再战**、**Summa 表情互发**（9 种情绪）
- **掉线不用慌**：60 秒内可自动重连；房主掉线会自动把房主身份**迁移**给别人，对局不散
- **需要**：自己搭服务器（见第九节）

### ⑧ 测试模式（自由练习）**← 新手强烈建议先来这里**

- **怎么进**：主界面 → 测试模式（点了就直接进）
- **怎么玩**：**没有目标格、没有禁止区、没有锁定、没有倒计时**，想画什么画什么
- 还可以用右下角的缩放按钮把棋盘从 ±5 调到 ±50
- **适合**：熟悉键盘操作、验证一个函数长什么样、给同学讲解

### ⑨ 关卡编辑器（自己做关卡）

- **怎么进**：闯关模式 → 关卡编辑器
- **怎么玩**：在 20×20 画布上摆放目标格（左键，绿）和禁止区（右键，红），
  还能用长方形/直线/画笔批量涂、框选移动、调坐标精度（1/1、1/2、1/4…）
- **导出去分享**：点「导出全部」或「下载关卡文件」生成 `.js` 文件发给朋友
- **导入别人的**：点「导入」，选文件或直接粘贴文本
- **注意**：自制关卡不参与官方进度和排行榜

## 七、一个回合的完整时序

每个回合固定按这 6 步走，**不可跳过顺序**：

```
① 选目标格  →  ② 设禁止区  →  ③ 锁元素  →  ④ 写函数  →  ⑤ 判定  →  ⑥ 换人
   （出题人）        （出题人）      （出题人）     （答题人）     （系统）    （双方）
```

### 棋盘会随回合变大

对战棋盘每次扩展都在第 5/9/13/17/21 回合开始时发生：

| 回合 | 范围 | 大小 |
|------|------|------|
| 1 ~ 4 | ±5 | 10 × 10 |
| 5 ~ 8 | ±6 | 12 × 12 |
| 9 ~ 12 | ±7 | 14 × 14 |
| 13 ~ 16 | ±8 | 16 × 16 |
| 17 ~ 20 | ±9 | 18 × 18 |
| 21 ~ 24 | ±10 | 20 × 20 |

> 闯关模式和竞速模式固定 20×20，不扩展。

### 各项数量上限（随回合增长）

| 项目 | 第 1~4 回合 | 第 5~8 回合 | 第 9~16 回合 | 第 17 回合起 |
|------|------------|------------|-------------|-------------|
| 目标格 | 由难度决定（1/2/3 个） | 同左 | 同左 | 同左 |
| 禁止区 | 1 个 | 1 个 | 2 个 | 3 个 |
| 锁定元素 | **0 个（无此阶段）** | 1 个 | 1 个 | 2 个 |

### 倒计时

- **选格 / 设禁区 / 锁定阶段**：首次 30 秒，超时后再给 20 秒宽限
- **写函数阶段**：第 1~4 回合 40 秒，之后每 4 回合 +10 秒，最高 90 秒
- 以上数字都要**乘以你选的时间倍率**
- 剩余 5 秒时会「滴答」响
- **闯关 / 竞速 / 测试模式没有任何倒计时**

### 关于锁定元素的细节

- **不能锁**：变量 `x` 和括号
- 同一个元素跨回合**最多累计被锁 2 次**，锁满后按钮变灰
- **简单难度下四则运算 `+ - * /` 受保护，不可锁定**（角标显示 protected）

## 八、卡住了？问题对号入座

### 打不开 / 白屏

1. 确认 `files/` 文件夹和 `index.html` **在同一目录下**，没有被拆散
2. 换成第二节的本地服务器方式打开

### 「一些图形化模块尚未定义」/ 界面错乱

用本地服务器（`python -m http.server`）打开，别用 `file://` 直接双击。

### 写函数的键盘不见了

输入函数阶段才会出现。如果被收成了圆形小按钮，**点那个圆形按钮**就能重新展开。

### 表达式明明对，还是判失败

按顺序检查这三条：

1. **有没有用到被锁定的符号？** 被锁的按钮带红色锁，点不了 —— 换个表达方式绕过去
2. **函数图像有没有碰到禁止区（红格）？** 碰一下就判失败
3. **有没有命中全部目标格（绿格）？** 一个都不能漏

### 反三角函数按钮是灰的 / 带锁

需要**通关全部 19 个分数关**才能解锁（分数关要先通关全部简单难度才开放）。

### 锁定元素的按钮为什么是灰的

前 4 回合本来就没有锁定阶段（上限 0）；另外同一个元素累计锁 2 次后也会变灰。

### 排行榜显示「无法连接排行榜服务器」

服务器没启动或网络不通。**不影响任何单机玩法**（闯关、竞速、测试、本地对战、人机对战都正常）。

### AI 训练卡住不动

浏览器在后台标签页会被限速。**保持页面前台**，别切走，等它训练完。

### 竞速下一级进不去

需要通关当前等级**全部 10 题**。

### 排行榜里想改名字

用户名即展示名，**注册后不可修改**。

### 超时了怎么办

倒计时归零会直接扣 1 分换人。**想不清楚就先写个保险的简单答案，拿 1 分也是分。**

## 九、联机要自己搭服务器

**只玩单人模式（闯关 / 竞速 / 测试 / 人机）和本地双人 —— 完全不需要服务器。**

只有 **联机对战 / 联机竞速 / 在线排行榜** 需要。本发布包**不含 `server/` 目录**，
服务器代码在开源仓库里：<https://github.com/shaihai-studio/fnchess>

### 原理（一句话）

联机用的是 **WebRTC 点对点直连**：服务器只负责帮你和对手「交换联系方式」，
连上之后**棋局数据在你们两人之间直接传输**，服务器看不到也不保存对局内容。
好处是延迟低、隐私好；代价是必须先有这台服务器帮你们牵线。

### 需要什么

- 一台有**公网 IP** 的服务器（云主机即可）
- **Node.js 18+**
- 放行端口（默认 `9000`）
- **HTTPS/WSS**（如果游戏页面是 https 打开的，这个必须配，否则浏览器会拦截）

### 三步搭起来

```bash
# 1. 拿到 server 目录
git clone https://github.com/shaihai-studio/fnchess.git
cd fnchess/server

# 2. 装依赖并启动（默认监听 9000）
npm install
npm start

# 3. 验证活着（返回一串随机 id 就对了）
curl http://你的域名:9000/peerjs/id
```

然后**在游戏里把服务器地址改成你自己的** —— 配置位置在 `files/js/P2PController.js`：

```js
P2PController.signaling = {
    host: '你的域名',
    port: 443,          // 用了 HTTPS 就是 443
    secure: true,       // 用了 HTTPS 就写 true
    path: '/'
};
```

> **也可以不改源码**：在 `index.html` 的 `<head>` 里、`P2PController.js` **之前**插一段：
> ```html
> <script>
>   window.P2P_SIGNALING = { host: '你的域名', port: 443, secure: true, path: '/' };
> </script>
> ```

### 两个必踩的坑

**坑 1：CSP 会拦住你的域名。**
`index.html` 里有一行 `Content-Security-Policy` 的 `connect-src`，换了域名必须一起加进去，
否则请求会被浏览器直接挡掉：

```html
connect-src 'self' wss://你的域名:443 https://你的域名:443;
```

**坑 2：HTTPS 页面连 HTTP 服务器 = 混合内容，必被拦。**
游戏用 https 打开，信令服务器**必须**也是 https/wss。
最省事的做法是用 **Nginx 反代 + Let's Encrypt 免费证书**，并且**别忘了这两行**：

```nginx
proxy_set_header Upgrade $http_upgrade;
proxy_set_header Connection "upgrade";
```

少了它们 WebSocket 握手会失败，症状是「页面能开，但一直连不上对手」。

### 还是连不上？

如果**房间能建、能看到对方，但一直停在「正在连接」**，大概率是双方都在**对称型 NAT**
（公司网、校园网、部分 4G/5G）后面，需要 **TURN 中继**（建议用 coturn）帮忙转发。

先查原因：`curl https://你的域名/peerjs/id` 有没有返回 id →
没返回就是服务器/端口/CSP 的问题；有返回但连不上，就是 NAT 问题，上 TURN。
