## 一、第三方代码

### 1. KaTeX —— 数学公式排版引擎

- **用途**：输入表达式时实时渲染标准 LaTeX 数学公式
- **位置**：`files/vendor/katex/`（`katex.min.js`、`katex.min.css`、`fonts/` 字体子目录）
- **版权**：Copyright (c) Khan Academy
- **许可**：**MIT License**（与 AGPL v3 兼容，可自由使用与再分发）
- **说明**：本地离线分发，不依赖 CDN

### 2. PeerJS —— WebRTC 点对点联机库

- **用途**：联机对战 / 联机竞速的点对点连接建立
- **位置**：`files/vendor/peerjs/peerjs.min.js`
- **许可**：**MIT License**
- **说明**：作为 CDN 加载失败时的本地回退，保证离线可用

### 3. geogebra-lite —— 曲线绘制引擎

- **用途**：绘制函数图像（自适应采样、曲线折线化）
- **位置**：`files/geogebra-lite/`
- **来源**：改编自开源项目 [GeoGebra](https://www.geogebra.org/) 的绘图算法
  （包含 Cohen-Sutherland 直线裁剪 + 自适应采样 + 曲线折线段绘制）
- **上游许可**：**GNU General Public License v3**
- **兼容性说明**：按照 GPL v3 条款，本项目的 **AGPL v3** 许可证与 **GPL v3 兼容**，
  因此可以在 AGPL v3 项目中使用 GPL v3 代码

> **注意**：若你修改并分发本项目中改编自 GeoGebra 的部分，需同样遵守 GPL 系许可的开源义务。

### 4. 自托管服务端依赖（不随本发布包分发）

仅在**自行部署信令服务器**时需要，本离线发布包内**不含 `server/` 目录**：

| 依赖 | 用途 | 许可 |
|------|------|------|
| `express` | HTTP 服务框架 | MIT License |
| `peer` | PeerJS 服务端 | MIT License |
| `ws` | WebSocket 服务 | MIT License |
