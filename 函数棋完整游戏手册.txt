> **口径说明（2026-08-15）**：本手册的玩法/机制说明以**代码实际实现为准**。若与游戏运行表现不一致，一律以代码为准；具体数值（关卡数、段位阈值、结算规则、函数白名单等）以 `files/js/*` 与 `server/index.js` 的最新版本为准。

本手册面向玩家与开发者，系统介绍函数棋的完整玩法、各种场景下界面的形态、

================================================================================
第一部分 玩法介绍
================================================================================

函数棋是一款「数学函数 + 策略对战」的回合制网页游戏。核心玩法：一方在坐标系
棋盘上挑选"目标格"，另一方编写数学函数表达式，让函数图像穿过目标格得分，同时
避开对手设置的"禁止区"。表达式越简洁，得分越高。

一、基本流程（本地/联机对战，一个回合的完整顺序）
  1. 选格阶段（SELECT_TARGET）：当前回合的"选格者"点击棋盘挑选目标格。
  2. 禁止区阶段（SET_FORBIDDEN）：选格者设置禁止区（书写者的函数图像
     不得穿过的格子），给书写者增加难度。
  3. 锁定阶段（SET_LOCKS）：选格者锁定若干数学元素（如 +、sin、数字等），
     书写者本轮写出的表达式里不能使用这些被锁定的元素。
  4. 输入函数阶段（INPUT_FUNCTION）：书写者（选格者的对手）用元素按钮/
     键盘构建函数表达式，系统求值、绘制函数图像并判定命中。
  5. 结算阶段（EVALUATE）：判定命中目标格 / 进入禁止区，结算本回合得分。
  6. 换人阶段（SWITCH_PLAYER）：交换角色，进入下一回合。

  角色关系：每个回合"选格者"负责选目标格、设禁止区、锁元素（相当于出题人），
  书写者（对方）负责写函数解题并得分。选格者规则从头到尾不变：奇数回合 B 选、
  偶数回合 A 选（第 1 回合 B、第 2 回合 A、第 3 回合 B…）。
  禁止区从第 1 回合起就有（第 1~8 回合上限 1 个），只是锁定元素前 4 回合
  上限为 0（即没有锁定阶段），第 5 回合起锁定上限 1 个，第 13 回合起 2 个。

二、棋盘与坐标系
  - 画布中心为原点，横轴 x（向右为正）、纵轴 y（向上为正）。
  - 本地/联机对战棋盘范围随回合自动扩展（每次扩展发生在第 5/9/13/17/21
    回合开始时）：
      回合 1~4   → ±5（10×10）
      回合 5~8   → ±6（12×12）
      回合 9~12  → ±7（14×14）
      回合 13~16 → ±8（16×16）
      回合 17~20 → ±9（18×18）
      回合 21~24 → ±10（20×20）
  - 闯关模式固定 20×20（坐标 -10~9）；竞速模式固定 20×20。
  - 格子是单位网格：选格时点击的是坐标点，实际判定的是以该点为中心的
    单位格子区域。

三、函数表达式
  - 以变量 x 为核心的数学表达式，如 x+1、x^2、sin(x)。
  - 支持：+ - * / ^ ! 括号；sin/cos/tan/abs/exp/ln/log/sqrt；
    反三角函数 asin/acos/atan（需通关全部分数关解锁，见 3.11）；
    常量 π、e、i（虚数单位）。中间计算支持复数，图像只在虚部足够小时可绘制。
  - 系统把表达式在棋盘范围内逐像素采样，绘制成连续折线（函数图像）。
  - 折线穿过目标格 = 命中；穿过禁止区 = 犯规（直接判失败，扣 1 分）。

四、得分规则
  - 命中全部目标格且未触碰禁止区 → 成功，按表达式的 token 数量（简洁度）
    得分：
      1~2 个 token   → 5 分
      3~5 个 token   → 4 分
      6~9 个 token   → 3 分
      10~15 个 token → 2 分
      更长           → 1 分
    表达式越简洁得分越高（与函数类型无关）。
  - 未命中全部目标格 或 进入禁止区 → 扣 1 分。
  - 超时（书写阶段倒计时结束）→ 扣 1 分并直接进入下一回合。
  - 本地/联机对战：所有回合结束后比较双方总分，分高者胜。

五、游戏模式一览
  ① 本地对战：两人轮流操作，可设难度/回合数/时间倍率。
  ② 人机对战（AI）：对手是 AI「Summa」，玩家固定为 A。
  ③ 闯关模式：单人，90 个官方整数关卡 + 19 个分支关（1/2~1/20，分为简单、
     普通、困难、专家、无解难度），每关预设目标格/禁止区/锁定元素，通关解锁
     下一关，按表达式简洁度评 1~5 星；也支持导入自制关卡包。
  ④ 竞速模式（标准竞速）：单人，30 个等级、每级 10 题随机谜题，固定 20×20
     棋盘；从等级 1 逐级晋级，按总用时评 1~5 星；每题失败可无限重试不扣时间。
  ⑤ 竞速试炼场（自定义竞速）：可自定义允许区/禁止区/锁定元素数量，随机生成
     一盘自定谜题，不晋级、不计星级、不记录最佳成绩。
  ⑥ 联机竞速（2~4 人）：同场竞速，实时比拼速度与排名，支持排位/休闲。
  ⑦ 联机对战（P2P）：通过 PeerJS 直连 1v1，支持排位（ELO）与休闲。
  ⑧ 测试模式：自由绘制函数，无目标/禁止/锁定/时限，可缩放棋盘。
  ⑨ 关卡编辑器：制作自定义闯关关卡包（可导入/导出）。

第二部分 界面与按钮详解
================================================================================

（本章按"进入游戏后你会依次看到什么"的顺序，逐界面说明布局、各按钮反应
  与交互反馈。）

--------------------------------------------------------------------------------
2.1 启动封面（首次加载 splash）
--------------------------------------------------------------------------------
出现时机：页面加载完成后首次显示。
界面形态：深色全屏遮罩，中央显示游戏大标题「函数棋」，下方提示
  "点击屏幕 / 按 回车·空格·ESC 进入"。
按钮反应：
  - 点击屏幕任意位置 → 播放转场动画（旋转+放大+虚化→白闪，约 0.9 秒），
    然后进入「开始界面」（标题页）。
  - 按 Enter / 空格 / ESC → 同上。
  - 转场期间再次点击无效（防止重复进入）。

--------------------------------------------------------------------------------
2.2 开始界面（标题页 start-page）
--------------------------------------------------------------------------------
界面形态：背景显示函数棋主标题图（MainTitle.png），中央一个醒目的
  「开始游戏」大按钮，下方有「关于我们」文字链接。
按钮反应：
  - 「开始游戏」→ 进入「主界面」（模式选择页）。
  - 「关于我们」→ 新标签页打开作者 B 站主页
    （https://space.bilibili.com/3690976753223882）。
  - 按 Enter / 空格 → 等同点击「开始游戏」。
  - 按 ESC → 关闭开始界面弹窗，返回「启动封面」。

--------------------------------------------------------------------------------
2.3 主界面（main-page，模式选择页）
--------------------------------------------------------------------------------
界面形态（左右两栏布局）：
  左上角：圆形返回箭头按钮（返回「开始界面」）。
  左栏（自上而下）：
    - 游戏标题图（MainTitle.png）。
    - 难度选择器（stepper，左右箭头 + 中间数值，如「简单 - 1个目标格」）。
    - 回合数选择器（如「8 回合（快速对战）」）。
    - 时间倍率选择器（如「普通棋」）。
    - 反三角函数开关（复选框「对战使用反三角函数 asin/acos/atan」，
      需通关全部分数关后解锁；未解锁时点击弹提示）。
  右栏（自上而下）：
    - 右上角两个圆形图标按钮：背景音乐设置（音符图标）、在线排行榜（奖杯图标）。
    - 模式按钮组（竖向）：「对战模式」「闯关模式」「竞速模式」「测试模式」。
      其中对战模式/闯关模式/竞速模式点击后会展开子菜单：
        - 对战模式 → 本地对战 / 人机对战 / 联机对战
        - 闯关模式 → 经典闯关 / 关卡编辑器
        - 竞速模式 → 标准竞速 / 竞速试炼场 / 联机竞速
    - 模式提示小字（如"本地对战：两位玩家轮流操作"）。
    - 「开始游戏」大按钮（StartButton.png）。

选择器（stepper）的按钮反应：
  - 点难度「左/右」箭头 → 在 简单/普通/专家 之间切换，数值文字与箭头
    颜色随之变化（简单绿、普通蓝、专家金）。注意：难度决定目标格数量
    （简单 1 个 / 普通 2 个 / 专家 3 个）。
  - 点回合「左/右」箭头 → 在 8/12/16/20/24 回合之间切换，颜色从蓝到红渐变。
  - 点时间「左/右」箭头 → 在 超慢棋/慢棋/普通棋/快棋/超快棋 之间切换，
    对应全部阶段倒计时的倍率（2.0/1.5/1.0/0.75/0.5）。
  - 键盘方向键：在开始界面可直接按 ←/→ 调整当前聚焦的选择器
    （难度/回合/时间）。
  - 选中模式为 闯关/测试/竞速/联机对战（P2P 子模式）时，难度/回合/时间
    三个选择器会被禁用（变暗、不可点），因为这些模式不需要这些参数。

模式按钮的反应：
  - 点击「对战模式」→ 高亮并展开子菜单；再点子菜单（本地/人机/联机）
    切换 _battleSubMode，提示小字同步更新。
  - 点击「闯关模式」→ 高亮并展开「经典闯关/关卡编辑器」子菜单。
  - 点击「竞速模式」→ 高亮并展开「标准竞速/竞速试炼场/联机竞速」子菜单。
  - 点击「测试模式」→ 高亮，无子菜单。
  - 只有「对战模式→本地/人机」时难度/回合/时间选择器才可用。

「开始游戏」按钮反应（按当前所选模式分派）：
  - 本地对战 / 人机对战 → 直接开局（进入对局界面）。
  - 人机对战：若该难度 AI 模型尚未训练，会先弹出「唤醒 Summa」训练弹窗
    （见 2.16），训练完成后才开局。
  - 经典闯关 → 打开「闯关模式」弹窗（选难度/选关）。
  - 关卡编辑器 → 就地打开「关卡编辑器」界面（2.15）。
  - 标准竞速 → 打开「竞速模式」弹窗（选关）。
  - 竞速试炼场 → 打开「竞速试炼场」自定义弹窗。
  - 联机竞速 → 打开「联机竞速」房间弹窗。
  - 联机对战 → 先弹「选择对战模式」（排位/休闲），再打开联机房间弹窗。
  - 测试模式 → 直接进入测试界面。

其他：
  - 「背景音乐」按钮 → 打开背景音乐设置弹窗（见 2.14）。
  - 「在线排行榜」按钮 → 打开排行榜弹窗（见 2.13）。
  - 按 ESC：主界面 → 返回「开始界面」；开始界面 → 返回「启动封面」。
  - 点击弹窗遮罩（弹窗外围）→ 等同按 ESC，返回上一层。

--------------------------------------------------------------------------------
2.4 对局界面（本地/人机/闯关/竞速共用画布 + HUD）
--------------------------------------------------------------------------------
进入对局后，浏览器会显示以下区域：

【顶部信息栏（HUD）】
  - 最左：玩家 A 徽标 + 实时分数（如「玩家A 0分」）。
  - 中央：游戏标题「函数棋」；其下方是回合显示条「回合 1/8」
    （当前回合 / 总回合）。回合进行到后段时回合数字颜色随进度变化
    （由绿→黄→红渐深）。
  - 最右：玩家 B 徽标 + 实时分数。
  - 单人模式（闯关/竞速）：顶部显示「Lv. N」关卡徽标
    （campaign-level-badge 圆角徽标，颜色随关卡难度变化：
    简单绿 / 普通黄绿 / 困难金 / 专家橙 / 无解红）。竞速模式下
    round-display（回合条）隐藏，左上角改显示实时用时。
  - 顶栏右侧另有一个背景音乐按钮（音符图标，点击开 BGM 设置弹窗）。

【画布四个角的信息块】
  - 左上角：饼图倒计时（环形进度 + 中间秒数，仅对战模式输入/选格阶段
    显示剩余时间；闯关/竞速/测试不显示）。
  - 左上角（其下/旁）：竞速实时用时（仅竞速模式，如 12.34s）。
  - 右上角：当前操作玩家名（如「玩家 A」）。
  - 底部中央：当前阶段提示文字（如「请点击棋盘选择目标网格」、
    「请编写你的函数」等）。

【棋盘画布（canvas）】
  - 坐标系网格：横轴 x、纵轴 y，原点位于画布中心，带坐标刻度。
  - 允许选格范围以高亮边框标出（随回合扩展的动态边界：第 1~4 回合 ±5、
    之后每 4 回合扩展 1，最大 ±10）。
  - 目标格以绿色格高亮（带序号 T1/T2…），禁止区以红色格标出（F1/F2…）。
  - 对战模式的画布上方会显示当前选格者/书写者横幅（如「A 选格，B 写函数」）。
  - 函数图像绘制时以折线动画从左侧逐步扫过棋盘。

【屏幕右下角悬浮的圆形按钮】
  - 「✓ 确认」：确认当前阶段（等同回车）。
  - 「← 退出」：退出当前对局。点击弹出「退出确认」气泡框（中央小卡片：
    「确定要退出当前对局吗？」，含「确认退出」「取消」两个按钮）。
    再点一次「←」或点气泡外任意处也可收起气泡；点「取消」不退出。
  - 「表情」：P2P 联机对局中显示（表情入口，见 2.10）。
  - 观战模式（观众视角）下这些圆形操作按钮会被隐藏。
  - 注：早期版本曾有「跳过本阶段」按钮（设置禁止区/锁定阶段跳过），
    现已被移除，不再显示。
  - 画布右下角（✓确认 按钮上方）：闯关模式会出现「绘制后等待」药丸
    （0s/1s/5s 三档），用于调节函数图像绘制完成到自动结算之间的等待时间；
    0s 立即结算，1s/5s 稍作停留便于观察函数图像。竞速/对战/测试模式
    不显示该药丸。

【悬浮输入栏（float-keypad）】
  - 输入函数阶段与锁定阶段才会出现（见 2.5 详述）。平时隐藏。

【主要阶段的操作反馈】
  - SELECT_TARGET（选格）：棋盘格子在选格者点击时亮起金框并标注序号；
    点击已选目标格可取消（变回普通格）；选满目标格后确认按钮变可用。
  - SET_FORBIDDEN（禁止区）：选格者点击棋盘格将格子标为红色（带「禁」字
    或叉号），再次点击取消；点「✓ 确认」提交。
  - SET_LOCKS（锁定）：悬浮键盘切换为"锁定视图"（见 2.5）。
  - INPUT_FUNCTION（书写）：悬浮键盘出现，棋盘网格被淡出并显示坐标系；
    顶部显示「书写你的函数」提示与「锁定元素」提示条。
  - EVALUATE（结算）：画布上播放函数图像从 x 轴起点逐渐绘制的动画
    （表达式越复杂绘制越慢；闯关可设 0/1/5s 的"绘制后等待"），
    命中目标格时目标格闪烁绿光；进入禁止区时禁止区闪烁红光。
  - SWITCH_PLAYER（换人）：显示「轮到 X」过渡动画（X 的大字头像 + 名称），
    稍作停顿后进入下一回合。

【结算横幅（对局中即时反馈）】
  - 本回合成功：在画布中央弹出得分横幅（如「✓ 成功 +3 分」），短暂停留后消失。
  - 本回合失败/超时：弹出红色横幅（如「✗ 失败 -1 分」/「超时！-1 分」）。
  - 本地对战最后回合结束后：弹出「游戏结束」结算弹窗（见 2.6）。
  - 闯关每关结束：成功弹「通关」弹窗（见 2.7），失败无弹窗直接重试。
  - 竞速每级结束（10 题全完成）：弹出竞速结算弹窗（见 2.8）。

【对局中途常见按键】
  - Enter：确认当前阶段（等同「✓ 确认」）。
  - Esc：关闭当前最上层弹窗 / 返回上一层（对局中未打开弹窗时无操作；
    退出对局请点右下角「← 退出」按钮）。
  - 方向键 ←/→：输入函数阶段移动表达式光标。
  - Backspace：输入函数阶段删除光标前一元素；Ctrl+Z：撤销上一步输入操作。

【对局中的「玩家」视角约定】
  - 本地对战：两人共用同一屏幕依次操作，顶部会明确标注当前轮到 A 还是 B。
  - 人机对战：你固定是 A，AI 是 B；轮到 B 时输入栏/键盘禁用并显示
    「AI 思考中…」动画，无需等待太久（AI 会快速完成）。
  - 闯关/竞速：你是唯一玩家，对手是系统预设的"目标格+禁止区"。

--------------------------------------------------------------------------------
2.5 悬浮输入栏（float-keypad，计算器式键盘）
--------------------------------------------------------------------------------
出现时机：INPUT_FUNCTION（书写函数）与 SET_LOCKS（锁定元素）阶段。
测试模式下也常驻显示。

界面形态（自上而下）：
  - 标题栏（可拖动，显示「表达式输入 · 可拖动」）：
    左端是标题文字；右端一排小按钮：「−」缩小、「+」增大、
    「遮光」背景模式（点击循环切换 透明/遮光/模糊）、「×」收起为圆形按钮。
  - 表达式显示区（float-keypad-display）：居中显示当前表达式（元素化排版），
    可点击定位光标。
  - KaTeX 数学预览区（float-keypad-math）：表达式下方常驻，实时渲染
    当前表达式为 LaTeX 数学公式；右下角有「100%」缩放按钮
    （100%/80%/60%/45% 循环，缩小后的字号随输入栏缩放）。
  - 主体（float-keypad-body）：5 列计算器式键盘：
        7 8 9 / ⌫
        4 5 6 * (
        1 2 3 - )
        0 . π + ^
        x e i ! AC
    其中「⌫」为删除光标前一个元素、「AC」为清空整个表达式。
  - 左侧函数面板（点击底部 fx 展开，3×3）：
        sin  cos  tan
        ln   √    abs
        asin acos atan
    反三角函数按钮在未解锁时带锁形图标，点击弹「未解锁」提示；
    锁定阶段面板布局相同，元素变为可开关的锁。
  - 底部操作栏（float-keypad-footer）：「◀」「▶」光标左/右移动、
    中部「fx」展开/收起函数面板、右侧「提交」（提交函数，等同回车）。

各按钮反应：
  - 数字/运算符/函数/x/e/i/π/^/! 等元素按钮 → 追加到表达式光标位置，
    表达式区与 KaTeX 预览实时更新；非法输入（如连续运算符）自动修正或提示。
  - 被锁定元素（选格者本轮锁定，书写者视角）→ 按钮带红色锁图标，
    点击播放错误音效，不能输入。
  - fx → 展开/收起左侧函数面板（输入栏宽度由 220 自动扩展到 360）。
  - ⌫ → 删除光标前一个元素；AC → 清空整个表达式。
  - ◀/▶ → 光标左/右移一格。
  - 提交 → 等同回车/主确认按钮：进入表达式求值、绘制与结算。
  - 标题栏按住拖动 → 整个输入栏可自由移动（自动限制在屏幕内）。
  - 「× 收起」→ 输入栏收成一个圆形浮动按钮；圆形按钮可拖动，
    单击重新展开为输入栏；收起时按钮右侧显示「y= 表达式」小预览条
    （随拖动移动）。
  - −/+（缩小/增大）→ 输入栏整体等比缩放（宽高、字号、按钮同步缩放，
    有缩放上下限并随 fx 展开态自动重夹）。
  - 背景模式按钮 → 输入栏背景在 透明/遮光/模糊 间循环切换（遮光为默认，
    按钮文字同步显示当前模式）。

SET_LOCKS（锁定）阶段的特殊形态：
  - 布局与输入阶段一致（fx 面板 + 主键盘），但标题变为
    「选择要锁定的元素 (已选数/可锁上限)」。
  - 主键盘与函数面板上每个元素按钮都是一个可开关的锁：
    点击选中（红色底）＝本轮锁定该元素；再次点击取消锁定。
  - 已锁满的元素变灰不可再选；四则运算（+ - * /）在简单难度下受保护，
    显示绿色「protected」角标且不可锁定。
  - 鼠标悬停元素按钮会弹出浮层，显示该元素当前回合的锁定次数
    （单元素最多锁 2 次，跨回合累计；超过上限自动变灰）。
  - 确认后进入输入函数阶段，被锁定元素在输入键盘上同步出现红锁。

2.7 闯关模式结算弹窗（campaign-victory / 失败）
--------------------------------------------------------------------------------
进入方式：主界面 → 闯关模式 → 经典闯关。

【闯关模式弹窗（选关）】
  - 第一步「选择难度」：显示难度按钮（简单/普通/困难/专家/无解/分数关
    1/2~1/20），已通关进度「已通关 X/81」与 LRΣ 技术分。
  - 分数关入口：通关全部简单难度（1~29）或已通关任意分数关后显示；
    反三角函数在通关全部 19 个分数关（1/2~1/20）后解锁（弹窗提示）。
  - 第二步「选择关卡」：进入所选难度范围后显示关卡网格（如 1~29 简单、
    30~53 普通、54~69 困难、70~81 专家、82~90 无解；1/2~1/20 分数关），
    每格显示关卡号，已通关的格子显示星数；未解锁的格子变灰不可点。
  - 顶部显示「已通关 X/Y」与 LRΣ 技术分；底部有「重置闯关进度」按钮
    （需两次确认）。

【闯关中界面】
  - 与 2.4 对局界面一致，但顶部为关卡徽标（Lv. N），无回合概念。
  - 目标格/禁止区/锁定元素全部由关卡数据决定（目标格 1 到多个不等；
    简单关通常 1~2 个，难度越高越多）。闯关无书写倒计时。
  - 画布右下角（✓确认 按钮上方）有「绘制后等待」药丸（0s/1s/5s）可调。

【通关结算弹窗（campaign-victory）】
  - 显示「第 N 关 通关！」大标题。
  - 星星行：1~5 颗金星（根据表达式简洁度/成绩评定）。
  - 记录行：显示 best record（该关最短表达式长度）与本次 score，若本次更短
    显示「new record（-x）」绿色；若更长显示「score（+x）」红色。
  - 彗星条：「彗星：X.X / 10 颗」进度条（对比全服该关最短表达式长度，
    本地无缓存时按满分 10 颗显示）。
  - 按钮：
    - 「下一关」→ 进入本难度的下一关（最后一关时提示"已完成全部"）。
    - 「重试本关」→ 重新开始本关。
    - 「返回选关」→ 回到关卡网格。
  - 通关分数关 1/20 时额外弹出「反三角函数已解锁」提示页。

【闯关失败反馈】
  - 失败时没有弹窗：画布弹出红色「失败」横幅（如「✗ 失败 -1 分」/
    「超时！-1 分」），随后自动回到输入阶段直接重试本关，不扣通关进度。

【退出闯关】
  - 对局中按 Esc → 「确认退出」→ 回到闯关弹窗的选关界面（保留进度）。

2.8 竞速模式（标准竞速）结算弹窗
--------------------------------------------------------------------------------
进入方式：主界面 → 竞速模式 → 标准竞速。

【竞速模式弹窗（选等级）】
  - 显示 30 个等级格（1~30），每格显示等级号与「最佳 12.34s」；
    未解锁的格显示「未解锁」（灰色不可点）；已通关等级显示最佳用时。
  - 顶部显示「共 30 关」与 TTΣ 累计最佳用时。
  - 底部有「重置竞速进度」按钮（需两次确认，可选保留/清除排行榜成绩）。

【竞速对局】
  - 开局播放全屏起跑倒计时「3、2、1、GO!」（环形动画 + 数字，带音效），
    GO! 后开始计时。
  - 每级随机 10 道题（固定 20×20 棋盘，坐标 -10~9），逐题挑战，
    左上角显示实时已用时间。
  - 每题允许区（目标格）数量由等级配置决定（1~6 个不等），禁止区数量
    1~300 个不等，锁定元素 0~15 个不等（21/22/27 等关禁止区极多，
    属"墙关"）。
  - 竞速模式没有书写倒计时（timeLimit=0），不限时，可慢慢思考。
  - 每题失败可无限重试（不计入总用时）。
  - 通关/失败都即时弹结算横幅，无弹窗打断。

【竞速结算弹窗（race-victory-modal）】
  - 顶部速度条装饰 + 等级标题（如「第 5 关 通过！」）。
  - 中部：本关总用时（如「12.34s」）与相对上一纪录差值（更快显示绿色
    「-3.21s 新纪录」，更慢显示红色「+1.50s」）；「best」行显示历史最佳。
  - 按钮（三个）：
    - 左侧圆形返回箭头「返回等级选择」→ 回到等级网格。
    - 「再次尝试」→ 重玩本等级（重新计时）。
    - 「进入下一等级」→ 通关后解锁下一级并直接开始（最后一关时提示完成）。

【竞速试炼场（自定义竞速）】
  - 弹窗三个步进器（左右箭头，可长按连续增减，也可直接键入数字）：
    允许区数量（≥1）、禁止区数量（≥0）、锁定元素数量（≥0）。
  - 校验规则：允许区+禁止区之和须 < 400；锁定元素上限为 20
    （启用反三角函数时 23），超限时底部红色提示「配置无效」。
  - 点「开始」随机生成一盘自定谜题直接开始；点「取消」/ESC 返回主界面。
  - 不晋级、不计星、不记录最佳成绩，纯练习用。通关结算弹窗可
    「重玩此配置」（沿用本次参数重开一盘）。

2.10 联机对战（P2P 1v1）房间弹窗与对局
--------------------------------------------------------------------------------
入口：主界面 → 对战模式 → 联机对战 → 开始游戏。

【第一步：选择对战模式】
  - 弹出「选择对战模式」小弹窗，两个大按钮：
    「排位对战」（计 ELO，默认）与「休闲对战」（不计分）。
  - 底部有「返回」按钮回到主界面。

【第二步：联机房间弹窗（p2p-room-modal）】
  - 顶部：标题「联机对战」，右上角关闭按钮（×）。
  - 状态栏：左侧状态圆点 + 文字（如「准备就绪」「正在创建房间…」
    「等待访客加入…」「正在加入房间…」「对手已连接！」）。
  - 三个页签：创建 / 加入 / 匹配大厅。
    - 创建页签：左侧三个参数选择器（难度、回合数、时间限制，可独立调节，
      初值与主界面当前值同步，发给对手）。右侧「创建房间」按钮。
      创建成功后：上方出现房间码显示条「房间码：123456 [复制]」、
      状态变为「等待访客加入…」，按钮变为「删除房间」。
      点「复制」把 6 位数字房间码复制到剪贴板并提示「房间码已复制」。
      点「删除房间」撤销建房（对局未开始则静默断开）。
    - 加入页签：输入框（6 位数字房间码）+「加入房间」按钮。
      输入非 6 位数字点加入 → 提示「请输入6位数字房间码」。
      房间码不存在/被占用 → 提示「加入失败：房间不可用」。
      输入的是竞速联机房间码 → 提示「该房间为竞速联机房间，请到竞速联机中进入」。
      加入成功后：状态变「已连接」，开始对局并进入对局界面。
    - 匹配大厅页签：WebSocket 连接大厅（显示「正在连接大厅…」→
      「大厅已连接，正在刷新房间列表…」）。房间列表按「与我的 ELO 距离」
      排序（休闲模式不分 ELO）；每个房间显示：
        - 等待房：「房主 昵称」「ELO 1234」（排位）、局参数描述 +「加入」按钮。
        - 对战房：「对战中 · 观众 N 人 · 参数」+「观战」按钮。
      「创建房间（进大厅）」按钮：在大厅登记一个长效房间（默认 5 分钟，
      显示到期倒计时；可切换"长效房间 30 分钟"开关；"允许观战"开关默认开启）。
      你的房间显示「删除房间」按钮。
      加入失败原因 ELO 太远 → 提示「房主开启了仅限相近ELO」。
  - 模式不匹配：排位玩家加入休闲房（或反之）→ 状态「该房间为排位/休闲房，
    与你的选择不符」，回到房间弹窗。

【对局开始】
  - 双方连接成功后自动隐藏房间弹窗，进入对局界面（见 2.4）。
  - 开场播放 VS 动画（双方头像 + 「VS」大字，约 2 秒）。
  - 顶部信息栏显示双方昵称与当前角色提示（你/A 或 对手/B）。

【对局中的联机特性】
  - 双方各在本地结算，通过消息同步；回合切换由「操作方」确认后广播给对端。
  - 轮到对手操作时：悬浮键盘禁用（按钮灰掉），顶部显示「等待对手操作…」。
  - 倒计时同步：非操作方以对手传来的倒计时为准刷新。
  - 对手超时 → 提示「对手超时！扣1分」。
  - 掉线重连（仅排位）：
    - 一方网络波动 → 弹「连接不稳定，正在重连…」；对方显示「等待对手重连」
      倒计时弹窗（最多 1 分钟）。
    - 重连成功 → 自动恢复对局（恢复对局进度弹窗）。
    - 重连失败 → 判负结算弹窗（见下方「断线结算」）。
    - 休闲模式不等待重连，直接断线结算。
  - 对手主动退出 → 立即弹「对手退出了对局」结算。
  - 对手发来 Summa 表情（比赛结束/你写了个好函数时）→ 屏幕中央弹出
    表情图片小窗（纯图片展示，无文字）。
  - 画布左下角有「表情」按钮（P2P 对局中显示）：点击弹出 Summa 表情面板
    （9 种情绪立绘），选择后发送给对方（观众也能看到）。
  - 右下角「← 退出」按钮：点后弹「确认退出」气泡框（再点一次/点遮罩取消）。
    排位对局中途退出将判负并扣 ELO，弹窗会明确提示。

【断线/中途退出结算（排位）】
  - 你掉线重连失败 → 弹「你已掉线，本局判负」结算，扣 ELO。
  - 对手掉线重连失败 / 对手主动退出 → 弹「对手中途退出，本局你获胜」
    结算，加 ELO。房主主动解散房间也按此对称判定。
  - 休闲模式 → 弹「房主已解散房间」或「对手已断开」，本局作废不计分。
  - 未开局（等待/匹配中）退出 → 中性文案「你已离开联机界面」，不判胜负。

【对局结束结算弹窗（P2P）】
  - 显示「游戏结束」，双方最终得分与胜负；若是判负还会标注原因
    （如「A 获胜！（B 中途退出）」、「A 获胜！（B 超时判负）」）。
  - ELO 变动提示：排位对局显示「ELO +18 / -12」等；休闲显示「休闲局，不计分」。
  - 按钮：「再来一局」→ 保持连接直接重开（角色不互换，参数沿用）；
    「返回主菜单」→ 断开连接回到主界面。

2.11 联机竞速（2~4 人实时竞速）
--------------------------------------------------------------------------------
入口：主界面 → 竞速模式 → 联机竞速 → 开始游戏。

【第一步：选择对战模式】同联机对战（排位竞速/休闲竞速）。

【第二步：竞速房间弹窗（race-battle-modal）】
  - 标题「联机竞速」，右上角关闭按钮。
  - 三个页签：创建 / 加入 / 匹配大厅。
  - 创建页签：
    - 左侧参数区：耐力选择器（1关 / 3关 / 5关 / 10关，圆点表示）
      与难度选择器（入门→传说 共 7 档）。耐力越高，可选难度上限越低
      （10 关最多选到「挑战」3 档、5 关到「熟练」5 档、3 关/1 关全开放）。
      难度选择器被耐力联动限制时自动回退。
    - 顶部显示「排位局 · 计竞速积分」或「休闲局 · 不增减积分」标签。
    - 「创建房间」按钮 → 生成 6 位房间码；「复制」按钮复制。
    - 成员列表：最多 4 人，每行显示「昵称 + 段位徽章 + 房主/访客 +
      已就绪/未就绪」；房主每行有「踢出」按钮；访客自己行有「就绪/取消就绪」。
    - 「开始竞速」按钮：需 2 人以上且全员就绪才可点击；人数不足显示
      「等待玩家...」，未全就绪显示「等待就绪...」，就绪后显示「开始竞速」。
    - 「删除房间」按钮（创建后出现）。
  - 加入页签：输入 6 位房间码 +「加入」按钮；已连房间后按钮变为「离开房间」。
    该页签隐藏参数区与开始按钮。
  - 匹配大厅页签：同联机对战大厅逻辑，但房间为竞速房；支持
    「长效房间（30 分钟）」与排位 ELO 相近过滤开关。
  - 房间码类型校验：在联机对战中输入竞速房间码（或反之）会提示模式不对。

【对局开始】
  - 全员就绪、房主点「开始竞速」→ 全屏覆盖「3、2、1、GO!」起跑倒计时
    （每步一秒、带音效，GO! 时播放起跑音）。

    1.8 秒后自动消失。

    （已通关关数/总关数）、各关用时列、领先者名字带金色光晕。
  - 各玩家独立在本地棋盘上竞速（无书写倒计时，不限时）；同关同题，
    以统一时间戳起跑杜绝抢先；完成一关自动进入下一关。
  - 房主广播进度与结算；断线玩家重连后同步进度。
  - 排位对局中途退出判负并扣竞速积分（提示「请勿消极比赛」）。

【对局结束结算弹窗】
  - 显示名次榜：🥇🥈🥉 奖牌 + 名次 + 昵称 + 用时（排位）或「休闲局」；
    弃权玩家显示「弃权」。

    （如 +23 / -18）、段位进度条（rankbar）。
  - 休闲局显示「休闲局 · 不增减积分」。
  - 完成名次的玩家显示「退出结算 / 继续观战」选择条。
  - 按钮：「再来一局」→ 保留房间重开（就绪状态清零需重新确认）；
    「返回主菜单」→ 断开连接回主界面。
  - 房主中途掉线 → 触发「房主迁移」：其他玩家选举新房主并继续对局
    （toast 提示新房主昵称），游戏不中断。

第三部分 机制详解
================================================================================

--------------------------------------------------------------------------------
3.1 回合流程与角色轮换
--------------------------------------------------------------------------------
【回合阶段机】一个回合按固定顺序推进：
  SELECT_TARGET（选格）→ SET_FORBIDDEN（设禁止区）→ SET_LOCKS（锁定元素）
  → INPUT_FUNCTION（写函数）→ EVALUATE（结算）→ SWITCH_PLAYER（换人）。

【选格者规则】
  - 全程奇数回合 B 选格、偶数回合 A 选格（第 1 回合 B、第 2 回合 A、
    第 3 回合 B…），始终不变。
  - 选格者负责本轮挑选目标格、设置禁止区、锁定元素；书写者（另一方）
    负责写函数并得分。
  - 禁止区从第 1 回合起就有（第 1~8 回合上限 1 个）；锁定元素第 1~4 回合
    上限为 0（自动跳过 SET_LOCKS），第 5~12 回合上限 1 个，第 13 回合起 2 个。

【阶段自动跳过】当某阶段不可用时自动跳过：
  - 前 4 回合 getMaxLockCount()===0 → 自动跳过 SET_LOCKS，直接从
    SET_FORBIDDEN 进入 INPUT_FUNCTION。
  - 禁止区达到上限后不可再添加；锁定元素达上限后按钮变灰。

--------------------------------------------------------------------------------
3.2 棋盘范围与扩展
--------------------------------------------------------------------------------
  - 本地/人机/联机对战：第 1~4 回合 ±5（10×10）、第 5~8 回合 ±6
    （12×12）、第 9~12 回合 ±7、第 13~16 回合 ±8、第 17~20 回合 ±9、
    第 21~24 回合 ±10（每 4 回合 +1，最大 ±10）。
  - 闯关：固定 20×20（坐标 -10~9），由关卡数据决定目标/禁区位置。
  - 竞速：固定 20×20（坐标 -10~9）。
  - 测试模式：初始 ±5，可通过缩放按钮在 ±5~±50 之间调整（步长 5）。
  - 单位网格判定：目标格/禁止区以格点为中心的单位正方形区域；函数折线
    穿过该区域即算命中/犯规。

--------------------------------------------------------------------------------
3.3 函数解析与绘制
--------------------------------------------------------------------------------
  - 表达式由 FunctionParser 解析为 AST；支持四则运算、幂 ^、阶乘 !、
    括号、sin/cos/tan、asin/acos/atan、abs、ln、sqrt、
    常量 π/e/i、变量 x。
  - 解析采用复数运算（i 参与计算），绘制时仅虚部绝对值足够小的点进入
    采样结果，因此 √(-1) 之类会产生复数中间结果的表达式也能得到有效图像。
  - 采样：在 x 轴范围内按像素密度采样，连接成折线绘制；采样密度固定，
    表达式越长绘制折线段越多，绘制动画越慢（配合"绘制后等待"可调节
    绘制完成后的停顿）。
  - 非法表达式（如 `x+` 结尾、括号不配对）：点确认时提示错误，不进入结算。

--------------------------------------------------------------------------------
3.4 结算判定与得分
--------------------------------------------------------------------------------
【判定】
  - 命中目标：折线穿过目标格区域。须命中全部目标格（hitTargets.length ≥
    targetCount）才算成功。
  - 犯规：折线穿过任一禁止区 → 直接失败。
  - 同时满足"命中全部目标格"且"未触碰禁止区"才算成功。

【得分】
  - 成功：按表达式 token 数量得分（ExpressionAnalyzer.analyzeFunctionType）：
      1~2 个 token   → 5 分
      3~5 个 token   → 4 分
      6~9 个 token   → 3 分
      10~15 个 token → 2 分
      更长           → 1 分
    （token 指 sin/cos/数字/常量 π/e/i/运算符/变量 x 等，与函数类型无关，
      越简洁得分越高。）
  - 失败（未命中全部目标格）：-1 分。
  - 犯规（进入禁止区）：-1 分。
  - 超时（倒计时结束未确认）：视阶段而定（详见 3.6）。
  - 闯关模式：成功得分为星级依据（1~5 星，表达式越短星越多）；
    失败本关不扣总分，可重试。
  - 竞速模式：不按得分判定，只看是否通关与耗时。

--------------------------------------------------------------------------------
3.5 禁止区与元素锁定机制
--------------------------------------------------------------------------------
【禁止区数量上限】（随回合增长）
  - 对战：第 1~8 回合最多 1 个；第 9~16 回合最多 2 个；第 17 回合起最多 3 个。
  - 竞速：固定最多 2 个。
  - 已达到上限时再点新增 → 替换最后一个（改选模式），并播放提示。

【锁定元素机制】
  - 锁定对象：数字（含 π/e/i）、运算符（+ - * / ^ !）、函数（sin 等）均可。
  - 不可锁定：变量 x、括号（ ）（代码硬性禁止）。
  - 每回合可锁定数量（对战）：第 1~4 回合 0；第 5~12 回合 1；第 13 回合起 2。
  - 竞速模式：固定最多锁 2 个。
  - 同一元素跨回合累计最多锁 2 次（elementLockCounts 持久，达 2 后按钮灰）。
  - 简单难度下四则运算（+ - * /）受保护不可锁定。
  - 被锁定元素在书写阶段输入键盘上带红色锁图标，不可输入。
  - 锁定阶段 UI 与输入栏同布局：点击元素按钮切换锁定/解锁（红色底=已锁），
    顶部显示「选择要锁定的元素 (已选/上限)」，悬停显示该元素锁定次数。

--------------------------------------------------------------------------------
3.6 时间限制机制
--------------------------------------------------------------------------------
【选格/设禁/锁定阶段共用倒计时】（每回合进入这些阶段时重新开始）
  - 首次 30 秒（× 时间倍率）；超时后重新计时 20 秒（× 倍率）作为宽限。
  - 选格阶段超时：
    - 已选至少 1 个目标格（但未点确认）→ 不扣分，直接进入对方输入阶段
      （跳过禁止区/锁定）。
    - 一个目标格都没选 → 扣 1 分，然后由 A 重新选格。
  - 设禁/锁定阶段超时 → 扣 1 分，重新计时 20 秒；连续 3 次超时
    → 消极比赛判负（见 3.7）。
【书写阶段倒计时】（每回合进入输入阶段时计算，updateTimeLimit）
  - 第 1~4 回合 40 秒；第 5~8 回合 50 秒；第 9~12 回合 60 秒；
    第 13~16 回合 70 秒；第 17~20 回合 80 秒；第 21~24 回合 90 秒
    （每 4 回合 +10 秒，最高 90 秒）。
  - 书写阶段超时 → 扣 1 分并直接进入下一回合。
【时间倍率】（主界面选择器）
  - 超慢棋 ×2.0 / 慢棋 ×1.5 / 普通棋 ×1.0 / 快棋 ×0.75 / 超快棋 ×0.5。
  - 倍率作用于上述所有倒计时。
【其他】
  - 联机模式：非操作方显示对手驱动的倒计时（timer_sync），本地不自跑，
    避免双方计时不一致。
  - 剩余 ≤5 秒时播放"滴答"提示音。
  - 闯关/竞速/测试模式不启动任何倒计时（书写与选格均不限时），
    可慢慢思考。

--------------------------------------------------------------------------------
3.7 消极比赛判负（对战模式）
--------------------------------------------------------------------------------
  - 触发条件：设禁/锁定阶段连续超时 3 次（targetConsecutiveTimeouts ≥ 3）。
  - 触发后立即结束对局，判定该玩家为负（forfeitGame），结算弹窗明确标注
    「A 获胜！（B 超时判负）」之类原因。
  - 此机制确保"故意拖时间"无法取胜。

--------------------------------------------------------------------------------
3.8 联机对战（P2P）同步机制
--------------------------------------------------------------------------------
  - 传输：PeerJS（WebRTC 直连，需公网信令服务器）。
  - 状态同步：操作方确认阶段后广播 action + 完整状态快照（state_sync）；
    被动方应用快照。周期发送指纹（version/round/player/phase）校验双方一致；
    发现落后自动补发快照或请求重同步。
  - 关键确认重发：阶段确认带 key，直到对方回 ack 才停止，防止快照丢失。
  - 计时双驱动竞态保护：本地已有活动计时器时忽略对手 timer_sync。
  - 断线恢复：排位模式掉线后自动重连（最多 60 秒）；重连成功自动恢复对局，
    访客大退重开页面可通过 localStorage 恢复上下文请求快照续局。
  - 对手健康探测：超过阈值无消息 → 发送 health_check，对方回 ack 即停止
    补救循环并重新计时。
  - ELO 结算：由房主在对局结束时统一上报；断线弃权由双端各自上报、
    服务器按 roomKey 去重。结算完全对称（访客掉线=房主胜，房主掉线=访客胜）。

--------------------------------------------------------------------------------
3.9 联机竞速机制
--------------------------------------------------------------------------------
  - 房间上限 4 人；房主创建房间，访客加入，全员就绪（房主无需就绪）后
    房主点「开始竞速」。
  - 耐力档位决定连跑关数：1/3/5/10 关；难度 7 档（入门/进阶/熟练/挑战/
    困难/极限/传说），档位越高谜题越难。耐力 10 关最多选到「挑战」、
    5 关最多「熟练」、3 关/1 关全开放。
  - 起跑倒计时 3-2-1-GO!；每关开头播关卡特性卡 1.8 秒。
  - 每人独立解题，房主广播各成员进度与排名；掉线成员标记弃权并保留进度，
    结算时排最后。
  - 房主掉线触发房主迁移（新 host 选举，60 秒总超时兜底）。
  - 排位竞速计"竞速积分"（rsc 榜），房主统一上报，服务器按房间去重；
    中途退出判负扣分。

--------------------------------------------------------------------------------
3.10 竞速模式（单人）谜题与星级
--------------------------------------------------------------------------------
  - 30 个等级，每级 10 题随机谜题；固定 20×20 棋盘。
  - 每题失败可无限重试，不累计失败时间。
  - 通关判定：命中该题全部目标格且不触禁。
  - 等级通关后按该级 10 题累计用时评星：100 秒内 =5 星、150 秒内 =4 星、
    300 秒内 =3 星、1000 秒内 =2 星、更久 =1 星。记录最佳时间
    （localStorage），通关后解锁下一级。
  - 等级 1 始终解锁；通关某级解锁下一级（存 function_chess_race_unlocked_levels）。
  - TTΣ：所有已通关等级的最佳用时之和，在选关弹窗顶部显示。

--------------------------------------------------------------------------------
3.11 闯关模式（官方 81 关 + 分数关）
--------------------------------------------------------------------------------
  - 难度分区：1~29 简单、30~53 普通、54~69 困难、70~81 专家、82~90 无解；
    另设分数关 1/2 ~ 1/20（19 关，专属入口，通关全部简单难度或已通
    任意分数关后开放）。
  - 通关规则：命中本关全部目标格且不触禁即通关，解锁下一关。
  - 星级：1~5 星，依据本关表达式长度（越短星越多），存 best_stars。
  - LRΣ（技术分）：各关"最短表达式长度"累加生成的积分（可无限小数），
    通关自动上报排行榜。
  - 彗星分：单关对比全服最短表达式 token，越接近满分 10 颗，通关弹窗显示。
  - 反三角函数解锁：通关全部 19 个分数关后解锁 asin/acos/atan；
    解锁后可在普通及以上难度与对战模式使用（主界面开关控制）。
  - 自制关卡包：导入 JSON 关卡数组后按原始顺序进入，全部可玩无解锁，
    不参与官方进度/排行榜。

--------------------------------------------------------------------------------
3.12 人机对战（AI / Summa）
--------------------------------------------------------------------------------
  - AI 名为 Summa，采用本地神经网络模型（浏览器 localStorage 存储）。
  - 首次以某难度开局前必须训练（弹窗选择规模）；训练规模越大模型越强，
    耗时越长。已有模型可跳过或追加训练。
  - 难度影响 AI 策略参数：easy 目标选择随机性大、函数复杂度低；
    expert 目标/禁区/锁定几乎最优、函数复杂度 4。
  - AI 回合自动完成：选格（AITargetSelector）、设禁（AITargetSelector）、
    锁定（AIConstraintManager，会避开必用元素并针对玩家弱点）、
    写函数（AIFunctionBuilderSingle/Multi，自动适配被锁定元素，
    优先常值/一次/二次等简单类型；精确求解不成则用陡坡近似）。
  - AI 判定命中/犯规后自动确认并推进，无需玩家干预。

--------------------------------------------------------------------------------
3.13 测试模式
--------------------------------------------------------------------------------
  - 无目标格、无禁止区、无锁定、无倒计时、无回合概念。
  - 输入函数后点确认立即在棋盘上绘制图像；可连续输入多条，
    历史图像保存在 testModeFunctions 并叠加显示。
  - 棋盘范围默认 ±5，可通过右下角缩放按钮在 ±5~±50 之间调节；
    缩放时已有函数图像会按新范围重新采样绘制。
  - 退出不结算、不记录。

3.15 排行榜防作弊与上报机制
--------------------------------------------------------------------------------
  - LRΣ 上报附带每关最短表达式原文（levels + minTokens 载荷），服务器对
    "已验证最优"做边界检查（≥ 全服最优即接受），历史老玩家数据自动兼容。
  - 重复上报：LRΣ 只在上次上报值之后再提高才上报；竞速每关时间以更短者为准。
  - 举报：LRΣ/彗星榜他人行有「举报」按钮，举报后对方下次闯关成绩上报被
    强制核验；每 90 秒限一次。
  - 竞速/联机积分上报按房间去重（服务端按 roomKey / playerId 幂等）。
  - 服务端未启动时排行榜显示「无法连接排行榜服务器，请稍后重试」，
    游戏其余功能不受影响。

第四部分 常见问题与提示
================================================================================
  - 联机对战/竞速打不开：确认本地已启动信令服务器（node server/index.js），
    且双方处于可直连的网络；输入 6 位房间码必须为纯数字。
  - 排行榜显示"无法连接"：服务器未运行或网络不通，不影响单机玩法。
  - 悬浮键盘不见了：输入阶段才出现；若被收起为圆形按钮，点圆形按钮展开；
    关卡编辑器打开时输入栏会隐藏。
  - 反三角函数带锁：未通关全部分数关，通关后自动解锁。
  - AI 开始前卡在训练：浏览器可能在后台节流，保持页面前台直到训练完成。
  - 表达式一直失败：检查是否使用了被对手锁定的元素（带红锁不可输入）；
    检查函数是否触碰了禁止区；检查括号/运算符是否完整、表达式是否合法。
  - 本地对战为什么锁定元素按钮是灰的：锁定元素前 4 回合不可用
    （上限 0），第 5 回合起可用；每元素跨回合最多累计锁定 2 次，
    达到上限后该元素按钮变灰。
  - 竞速未解锁下一级：需通关当前等级全部 10 题。
  - 排行榜昵称改不了：昵称最长 10 个字符。
